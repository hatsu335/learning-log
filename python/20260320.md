## [仮想環境]


### 1. どちらの環境を使うべきか

- **プロジェクト開始時点では Anaconda を使っていなかった → venv で環境を作った**
- **その結果、プロジェクト直下に .venv フォルダがある**
- **途中から Anaconda をインストールしたため、conda activate が頭に残っている**

つまり、**このプロジェクトは venv の仮想環境を使うのが自然**

Anaconda を後から入れても、既存の `.venv` はそのまま使える

---

### 2. venv の仮想環境をアクティブにするコマンド（VS Code / Windows）
VS Code のターミナルは通常 **PowerShell** なので、次のコマンドを使います。

```powershell
.\.venv\Scripts\Activate.ps1
```

アクティブになると、プロンプトがこうなります：

```
(.venv) PS C:\your\project\path>
```

---

### 3. conda activate を使うべきケース
もしあなたが **conda で作った環境**を使いたい場合は、次のようにします。

```powershell
conda activate <環境名>
```

ただし、**.venv フォルダがあるプロジェクトでは、通常 conda は使いません。**

---

### 4. どちらの環境が実際に存在するか確認する方法

#### conda の環境一覧を見る
```powershell
conda env list
```

ここにプロジェクト用の環境名がなければ、  
**そのプロジェクトは conda ではなく venv を使っている**と判断できます。



## [仮想環境にインストールされているパッケージの確認方法]

### 1. 一覧を表示する（最も一般的）
```bash
pip list
```

### 2. 依存関係も含めて詳細に確認する
```bash
pip freeze
```
`pip freeze` は `requirements.txt` を作るときにも使われます。

### 3. 特定のパッケージの情報を見る
```bash
pip show パッケージ名
```

---

## [仮想環境を終了（deactivate）するコマンド]

### OS・環境に関係なく共通
```bash
deactivate
```

これだけで `.venv` から抜けて、通常の Python 実行環境に戻ります。

#### 補足：VS Code のターミナルを閉じたらどうなる？  
ターミナルを閉じると仮想環境は自動的に解除されます。  


## [conda と venv の終了コマンドの違い]

### conda（Anaconda / Miniconda）
```bash
conda deactivate
```

- conda の環境を抜けると、次のように `(base)` に戻ることが多いです。
- さらに完全に抜けたい場合は、もう一度 `conda deactivate` を実行すると `(base)` も消えます。

---

### venv（Python 標準の仮想環境）
```bash
deactivate
```

- `.venv` のような venv 環境では `conda deactivate` は使いません。
- venv の場合は常に `deactivate` だけで OK です。

---

## [どちらを使っているかの見分け方]

### conda の場合
- プロンプトに `(base)` や `(myenv)` のように **環境名だけ**が表示される。
- `.venv` フォルダがなくても動く。

### venv の場合
- プロンプトに `(.venv)` のように **フォルダ名がそのまま表示される**。
- プロジェクト直下に `.venv` フォルダがある。



## [まとめ]

| 種類 | アクティブ化 | 終了 |
|------|--------------|------|
| **conda** | `conda activate env名` | `conda deactivate` |
| **venv** | Windows: `.\.venv\Scripts\Activate.ps1`<br>macOS/Linux: `source .venv/bin/activate` | `deactivate` |

**追記**

```bash
# venv 作成
python -m venv .venv
```
