## [画像付きPDF作成から印刷まで]

 **Tkinter → PDF生成 → 図面PDFの画像化 → DBから値を取得 → 1枚のA4作業指示書を作成**  



### 全体構成

1. Tkinter から「作業指示書を作成」ボタンを押す  
2. データベースから注文情報を取得  
3. 図面PDFを画像化（1ページ目）  
4. ReportLab で A4タテのPDFを生成  
5. 上半分：作業指示（左）＋仮納品書（右）  
6. 下半分：図面画像を貼り付け  
7. 完成したPDFを保存 or 印刷

---

```
pip install reportlab PyPDF2 pdf2image pillow
```

※ Windows の場合、pdf2image のために **poppler** が必要  
（poppler の bin フォルダを PATH に追加）

## [画像付きPDF生成]

## 1. DB から値を取得するモジュール（db_manager.py）

```python
import pandas as pd
from sqlalchemy import create_engine

class DBManager:
    def __init__(self, engine_url):
        self.engine = create_engine(engine_url)

    def get_order(self, order_id):
        query = """
            SELECT
                o.expected_due,
                o.order_number,
                p.product_code,
                p.model_code,
                m.name AS material_name,
                p.inch,
                pt.name AS process_type,
                o.process_quantity,
                o.lot_number,
                o.quantity,
                p.drawing_path
            FROM orders o
            JOIN products p ON o.product_id = p.id
            JOIN materials m ON p.material_id = m.id
            JOIN process_types pt ON p.process_type_id = pt.id
            WHERE o.id = %s
        """
        df = pd.read_sql(query, self.engine, params=(order_id,))
        return df.iloc[0].to_dict()
```

## 3. PDF生成モジュール（pdf_generator.py）

```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfgen import canvas
from reportlab.lib.units import mm
from reportlab.lib.utils import ImageReader

def create_work_instruction(output_path, data, drawing_image):
    c = canvas.Canvas(output_path, pagesize=A4)
    width, height = A4

    # --- 罫線 ---
    c.setLineWidth(1)
    c.line(0, height/2, width, height/2)
    c.line(width/2, height/2, width/2, height)

    # --- 作業指示（左上） ---
    x_left = 10 * mm
    y_top = height - 20 * mm

    c.setFont("Helvetica-Bold", 14)
    c.drawString(x_left, y_top, "【作業指示】")

    c.setFont("Helvetica", 11)
    y = y_top - 10 * mm

    fields_left = [
        ("予定納期", data["expected_due"]),
        ("注文書・行程表", data["order_number"]),
        ("品番", data["product_code"]),
        ("型番", data["model_code"]),
        ("材料名", data["material_name"]),
        ("inch", data["inch"]),
        ("加工種類", data["process_type"]),
        ("加工数", data["process_quantity"]),
        ("ロットナンバー", f"{data['lot_number']}   （手書き欄：__________）"),
    ]

    for label, value in fields_left:
        c.drawString(x_left, y, f"{label}: {value}")
        y -= 7 * mm

    # --- 仮納品書（右上） ---
    x_right = width/2 + 10 * mm
    y = y_top

    c.setFont("Helvetica-Bold", 14)
    c.drawString(x_right, y, "【仮納品書】")

    c.setFont("Helvetica", 11)
    y -= 10 * mm

    fields_right = [
        ("予定納期", data["expected_due"]),
        ("注文書・行程表", data["order_number"]),
        ("品番", data["product_code"]),
        ("材料名", data["material_name"]),
        ("inch", data["inch"]),
        ("受注数", data["quantity"]),
        ("ロットナンバー", f"{data['lot_number']}   （手書き欄：__________）"),
    ]

    for label, value in fields_right:
        c.drawString(x_right, y, f"{label}: {value}")
        y -= 7 * mm

    # --- 下半分に図面画像を貼り付け ---
    img = ImageReader(drawing_image)
    img_width = width - 20 * mm
    img_height = height/2 - 30 * mm

    c.drawImage(img, 10 * mm, 10 * mm, width=img_width, height=img_height, preserveAspectRatio=True)

    c.showPage()
    c.save()
```

ここでは **Windows（業務アプリで最も一般的）を前提**に、Tkinter から PDF を印刷するための **実用的な2つの方法**をまとめます。

## 最も安定する印刷方法

### **方法①：Windows の既定プリンタで PDF を直接印刷（os.startfile）**
- Windows 標準機能  
- Adobe Reader や Edge が自動で印刷  
- Tkinter から簡単に呼び出せる  
- 追加ライブラリ不要  

---

## 方法①：Windows の既定プリンタで PDF を印刷（最も簡単）

```python
import os
import subprocess
import time

def print_pdf(file_path):
    # Windows の印刷コマンド
    # /p → 印刷、/h → 非表示
    acrobat = r"C:\Program Files\Adobe\Acrobat DC\Acrobat\Acrobat.exe"

    if not os.path.exists(acrobat):
        # Adobe が無い場合は Edge で印刷
        os.startfile(file_path, "print")
        return

    # Adobe Reader を使って印刷
    subprocess.Popen([acrobat, "/p", "/h", file_path])
    time.sleep(3)  # 印刷キューに入るまで少し待つ
```

### Tkinter から呼び出す

```python
from tkinter import messagebox

def on_print_button(self):
    pdf_path = "work_instruction.pdf"
    print_pdf(pdf_path)
    messagebox.showinfo("印刷", "印刷を開始しました。")
```

import win32print
import win32api

def print_pdf_win32(file_path):
    printer_name = win32print.GetDefaultPrinter()
    win32api.ShellExecute(
        0,
        "print",
        file_path,
        f'/d:"{printer_name}"',
        ".",
        0

## [Tkinter + PDF生成 + 印刷までの一連の流れ（統合例）]


```python
import tkinter as tk
from tkinter import messagebox
from db_manager import DBManager
from image_tools import pdf_to_image
from pdf_generator import create_work_instruction
from print_tools import print_pdf   # ← 印刷モジュール

class App:
    def __init__(self, root):
        self.root = root
        self.db = DBManager("mysql+pymysql://user:pass@localhost/dbname")

        tk.Button(root, text="作業指示書を作成", command=self.generate_pdf).pack(pady=10)
        tk.Button(root, text="印刷", command=self.print_pdf).pack(pady=10)

        self.last_pdf = None

    def generate_pdf(self):
        order_id = 745
        data = self.db.get_order(order_id)
        drawing_image = pdf_to_image(data["drawing_path"])

        pdf_path = "work_instruction.pdf"
        create_work_instruction(pdf_path, data, drawing_image)

        self.last_pdf = pdf_path
        messagebox.showinfo("完了", "PDFを生成しました。")

    def print_pdf(self):
        if not self.last_pdf:
            messagebox.showerror("エラー", "先にPDFを生成してください。")
            return

        print_pdf(self.last_pdf)
        messagebox.showinfo("印刷", "印刷を開始しました。")

root = tk.Tk()
app = App(root)
root.mainloop()
```

## [Poppler]

### pdf2image は *pip でインストールするだけでは不十分* です。  
### Windows では *Poppler のインストールが必須* です。**  
  [PyPI](https://pypi.org/project/pdf2image/)

---

### なぜ pip だけでは動かないのか？
`pdf2image` は PDF を画像に変換するための Python ライブラリですが、  
実際の変換処理は **Poppler（pdftoppm / pdftocairo）** という外部ツールに依存しています。

そのため：

- `pip install pdf2image` → Python ライブラリが入る  
- **Poppler がないと変換できない**（Windows では標準で入っていない）

という構造になっています。  
  [PyPI](https://pypi.org/project/pdf2image/)

---

### インストール手順（Windows）

### ① pdf2image を pip でインストール
```
pip install pdf2image
```
  [Men of Letters（メン・オブ・レターズ）](https://laboratory.kazuuu.net/convert-a-pdf-file-to-an-image-using-pdf2image-in-python/)

### ② Poppler をインストール（必須）
Windows では Poppler を手動で入れる必要があります。

1. Poppler for Windows をダウンロード  
   （推奨：oschwartz10612 の最新版）  
     [PyPI](https://pypi.org/project/pdf2image/)
2. ZIP を展開して任意の場所へ配置  
3. `bin/` フォルダを PATH に追加  
   または `convert_from_path()` に `poppler_path=` を指定

例：

```python
from pdf2image import convert_from_path

images = convert_from_path(
    "sample.pdf",
    poppler_path=r"C:\path\to\poppler-xx\bin"
)
```
  [Men of Letters（メン・オブ・レターズ）](https://laboratory.kazuuu.net/convert-a-pdf-file-to-an-image-using-pdf2image-in-python/)

---

### まとめ（重要ポイント）

| 項目 | 必要？ | 補足 |
|------|--------|-------|
| `pip install pdf2image` | ✔ 必須 | Python ライブラリ |
| Poppler インストール | ✔ 必須 | Windows では手動 |
| PATH 設定 | 任意 | `poppler_path=` を使うなら不要 |
| Pillow | 自動で入る | 画像処理用 |

---

### 結論（再掲）
**pdf2image は pip で入るが、Windows では Poppler を別途インストールしないと動かない。**
