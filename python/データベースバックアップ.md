# [データベースバックアップ]

はい、**PowerShellから実行して問題ありません**。むしろWindows環境では一般的なやり方です。

ただし、いくつか押さえておくべきポイントがあります。

---

# ① 基本の実行方法（PowerShell）

```powershell
mysqldump -u root -p honeycomb_db > backup.sql
```

実行すると：

* パスワード入力を求められる
* `backup.sql` が作成される

---

# ② よくあるエラー（ほぼ全員ここで詰まる）

## ■ エラー

```text
mysqldump : 用語 'mysqldump' は認識されません
```

👉 原因：

* PATHが通っていない

---

## ■ 解決①（簡単）

フルパスで実行：

```powershell
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p honeycomb_db > backup.sql
```

👉 `&` はPowerShellで「実行」を意味します

---

## ■ 解決②（恒久対応）

環境変数PATHに追加：

```text
C:\Program Files\MySQL\MySQL Server 8.0\bin
```

👉 これで `mysqldump` だけで実行可能

---

# ③ 出力先をNASにする

```powershell
mysqldump -u root -p honeycomb_db > \\NAS\backup\honeycomb.sql
```

👉 共有フォルダに直接保存可能

---

# ④ 日付付きバックアップ（実務向け）

```powershell
$date = Get-Date -Format "yyyyMMdd"
mysqldump -u root -p honeycomb_db > "backup_$date.sql"
```

---

# ⑤ 自動化（重要）

PowerShellスクリプト化：

```powershell
$date = Get-Date -Format "yyyyMMdd"
& "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -pパスワード honeycomb_db > "C:\backup\honeycomb_$date.sql"
```

👉 これをタスクスケジューラで実行

---

# ⑥ 注意点（重要）

## ■ パスワード直書き

```powershell
-pパスワード
```

👉 セキュリティ的には微妙

---

## ■ より安全な方法

```powershell
-p
```

👉 実行時に入力（手動用）

---

# ⑦ コマンドプロンプトとの違い

| 項目    | PowerShell | cmd |
| ----- | ---------- | --- |
| パス実行  | `&` 必要     | 不要  |
| 変数    | 強力         | 弱い  |
| スクリプト | ◎          | △   |

👉 **PowerShellの方が実務向き**

---
