## [PythonでCSVをMySQLに読み込む方法]

以下のようなCSVファイルを例にする

### `data.csv`

```csv
message,likes,area
"こんにちは",10,"Tokyo"
"おはよう",5,"Osaka"
"こんばんは",8,"Nagoya"
```

### 対象テーブル：`posts_input_file`

```sql
CREATE TABLE posts_input_file (
  id      INT NOT NULL AUTO_INCREMENT,
  message VARCHAR(140),
  likes   INT UNSIGNED,
  area    VARCHAR(20),
  PRIMARY KEY(id)
);
```

---

## 必要なライブラリ

まずは `mysql-connector-python` をインストール

```bash
pip install mysql-connector-python
```

---

## Pythonスクリプト例

```python
import csv
import mysql.connector

# MySQLに接続
conn = mysql.connector.connect(
    host='localhost',
    user='your_user',
    password='your_password',
    database='your_db',
    charset='utf8mb4'
)
cursor = conn.cursor()

# CSVファイルを開く
with open('data.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.DictReader(csvfile)
    for row in reader:
        # データを挿入
        cursor.execute(
            "INSERT INTO posts_input_file (message, likes, area) VALUES (%s, %s, %s)",
            (row['message'], row['likes'], row['area'])
        )

# コミットして終了
conn.commit()
cursor.close()
conn.close()
```

---

## 補足ポイント

- `DictReader` を使うと、CSVのヘッダーをキーにして辞書形式で読み込めるから便利
- `utf-8` で文字化けする場合は、`encoding='utf-8-sig'` や `encoding='cp932'`（Shift_JIS）も試す
- `cursor.executemany()` を使えば、まとめて挿入もできる（大量データ向け）

---

## まとめて挿入したい場合（高速化）

```python
data = []
with open('data.csv', newline='', encoding='utf-8') as csvfile:

cursor.executemany(
    "INSERT INTO posts_input_file (message, likes, area) VALUES (%s, %s, %s)",

)
```

これで**一括で挿入できる**から、パフォーマンスも良くなる

## まとめ

- `DictReader` で柔軟にデータを扱える
- `executemany()` で高速化も可能

## [PythonでCSVを読み込んでMySQLに挿入する際の「重複チェック」と「バリデーション」]

## 1. 重複チェックの考え方

### 方法①：テーブル側で制約を設ける（推奨）

たとえば、`message` と `area` の組み合わせがユニークであるべきなら

```sql
ALTER TABLE posts_input_file ADD UNIQUE KEY uniq_message_area (message, area);
```

これで、**同じ内容の投稿が複数回挿入されるのを防げる**

Python側では、重複していたらスキップするように `INSERT IGNORE` を使うと簡単

```python
cursor.execute(
    "INSERT IGNORE INTO posts_input_file (message, likes, area) VALUES (%s, %s, %s)",
    (row['message'], row['likes'], row['area'])
)
```

---

### 方法②：Python側で事前にチェックする

たとえば、すでに登録されている `message` と `area` の組み合わせを取得しておいて、重複していたらスキップ

```python
cursor.execute("SELECT message, area FROM posts_input_file")
existing = set((m, a) for m, a in cursor.fetchall())

with open('data.csv', newline='', encoding='utf-8') as csvfile:
    reader = csv.DictReader(csvfile)
    for row in reader:
        key = (row['message'], row['area'])
        if key in existing:
            print(f"重複スキップ: {key}")
            continue
        cursor.execute(
            "INSERT INTO posts_input_file (message, likes, area) VALUES (%s, %s, %s)",
            (row['message'], row['likes'], row['area'])
        )
```

## 2. バリデーションの例

### 例：以下の条件をチェック

- `likes` は整数で0以上
- `message` は空でない、かつ140文字以内
- `area` は20文字以内

```python
def is_valid(row):
    try:
        message = row['message'].strip()
        likes = int(row['likes'])
        area = row['area'].strip()
        if not message or len(message) > 140:
            return False
        if likes < 0:
            return False
        if len(area) > 20:
            return False
        return True
    except Exception as e:
        print(f"バリデーションエラー: {e} → {row}")
        return False
```

### 挿入時にバリデーションを適用

```python
for row in reader:
    if not is_valid(row):
        print(f"無効なデータをスキップ: {row}")
        continue
    cursor.execute(
        "INSERT IGNORE INTO posts_input_file (message, likes, area) VALUES (%s, %s, %s)",
        (row['message'], row['likes'], row['area'])
    )
```

## まとめ

| 機能 | 方法 |
|------|------|
| 重複チェック | `UNIQUE制約 + INSERT IGNORE` or Python側で事前チェック |
| バリデーション | Pythonで関数化してチェック（型・長さ・空欄など） |
| ログ出力 | `print()` や `logging` モジュールで記録可能 |

この仕組みを入れておけば、**CSVの品質が多少悪くても安心して読み込める**ようになる  


## [主キーやユニークキーが重複したときに、既存のレコードを最新に更新する]

**UPSERT（更新付き挿入）**

## 目的：主キーが重複していたら、内容を比較して必要に応じて更新

たとえば、こんなルール

- `id` が主キー
- 同じ `id` のレコードがすでに存在する場合：
  - `message`, `likes`, `area` が**すべて同じ** → 何もしない
  - どれかが違う → **更新する**

---

## 方法①：`INSERT ... ON DUPLICATE KEY UPDATE` を使う

```python
cursor.execute("""
    INSERT INTO posts_input_file (id, message, likes, area)
    VALUES (%s, %s, %s, %s)
    ON DUPLICATE KEY UPDATE
      message = VALUES(message),
      likes = VALUES(likes),
      area = VALUES(area)
""", (row['id'], row['message'], row['likes'], row['area']))
```

これで、**`id` が重複していたら更新**される

---

## 方法②：更新が必要なときだけ更新したい（差分があるときだけ）

MySQL 8.0 以降なら、**差分があるときだけ更新する**ように書くこともできる

```sql
ON DUPLICATE KEY UPDATE
  message = IF(VALUES(message) <> message, VALUES(message), message),
  likes   = IF(VALUES(likes)   <> likes,   VALUES(likes),   likes),
  area    = IF(VALUES(area)    <> area,    VALUES(area),    area)
```

これで、**値が変わっていないカラムは更新されない**から、更新ログやトリガーが無駄に動かなくて済む

---

## 補足：`VALUES()` とは

- `VALUES(column_name)` は、`INSERT` で指定した値を参照する構文。
- `ON DUPLICATE KEY UPDATE` の中で「新しい値」と「既存の値」を比較できる。

---

## Pythonでの実装例

```python
cursor.execute("""
    INSERT INTO posts_input_file (id, message, likes, area)
    VALUES (%s, %s, %s, %s)
    ON DUPLICATE KEY UPDATE
      message = IF(VALUES(message) <> message, VALUES(message), message),
      likes   = IF(VALUES(likes)   <> likes,   VALUES(likes),   likes),
      area    = IF(VALUES(area)    <> area,    VALUES(area),    area)
""", (row['id'], row['message'], row['likes'], row['area']))
```

---

## まとめ

| 処理内容 | 方法 |
|----------|------|
| 主キー重複時に更新 | `INSERT ... ON DUPLICATE KEY UPDATE` |
| 値が変わっているときだけ更新 | `IF(VALUES(col) <> col, VALUES(col), col)` を使う |
| Pythonから実行 | `cursor.execute()` でSQLを送るだけでOK |

この仕組みを使えば、**CSVの内容を「差分更新」しながら取り込む**ことができるから、  
「毎日更新されるデータを安全に同期したい」みたいなケースにも使える
