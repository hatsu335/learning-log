## [SQLAlchemyモジュール]

SQLAlchemy は大きく分けて **2つの使い方**があります。

| スタイル | 特徴 | あなたの用途 |
|---------|------|--------------|
| **Core** | SQL を Python で書く | UPDATE / INSERT の処理で使っている |
| **ORM** | Python クラスをテーブルとして扱う | マスタ登録スクリプトで便利 |

Honeycomb Excel読み込みは **Core** を使っています。  
これは「SQL を Python で書く」スタイルで、実務では非常に強力です。

---

## [SQLAlchemy Core の基礎]

## ① エンジン（DB 接続）

```python
from sqlalchemy import create_engine
engine = create_engine("mysql+pymysql://user:pass@host/dbname")
```

これは **DB への接続そのもの**です。

---

## ② メタデータ（テーブル情報の管理）

```python
from sqlalchemy import MetaData
metadata = MetaData()
```

---

## ③ 既存テーブルを読み込む（autoload）

```python
from sqlalchemy import Table
orders = Table("orders", metadata, autoload_with=engine)
```

これで `orders.c.column_name` のようにカラムへアクセスできます。

---

## ④ SELECT（読み込み）

```python
with engine.connect() as conn:
    result = conn.execute(orders.select())
    rows = result.fetchall()
```

---

## ⑤ UPDATE（更新）

あなたが使っている形：

```python
stmt = (
    update(orders)
    .where(orders.c.order_number == row["order_number"])
    .values(quantity=row["quantity"])
)
conn.execute(stmt)
```

これは **SQL の UPDATE 文を Python で書いているだけ**です。

---

## ⑥ INSERT（追加）

```python
stmt = orders.insert().values(
    order_number="123",
    quantity=10
)
conn.execute(stmt)
```

あなたは pandas の `to_sql()` を使って INSERT していますが、  
Core の INSERT も覚えておくと便利です。

---

## [SQLAlchemy ORM の基礎]（マスタ登録スクリプトで役立つ）

ORM は「テーブルを Python クラスとして扱う」スタイルです。

## ① Base クラスを作る

```python
from sqlalchemy.orm import declarative_base
Base = declarative_base()
```

---

## ② テーブルをクラスとして定義

```python
from sqlalchemy import Column, Integer, String

class Product(Base):
    __tablename__ = "products"

    id = Column(Integer, primary_key=True)
    product_code = Column(String(50))
    name = Column(String(100))
```

---

## ③ セッション（トランザクション管理）

```python
from sqlalchemy.orm import sessionmaker
Session = sessionmaker(bind=engine)
session = Session()
```

---

## ④ INSERT（追加）

```python
p = Product(product_code="ABC123", name="ハニカム材")
session.add(p)
session.commit()
```

---

## ⑤ UPDATE（更新）

```python
p = session.query(Product).filter_by(product_code="ABC123").first()
p.name = "新しい名前"
session.commit()
```

---

## ⑥ DELETE（削除）

```python
session.delete(p)
session.commit()
```

---

## Core と ORM の違いを一言で

| Core | ORM |
|------|------|
| SQL を Python で書く | Python クラスを SQL に変換 |
| 高速・柔軟 | 可読性が高い |
| あなたの Excel → DB 処理に最適 | マスタ登録スクリプトに最適 |

---

## あなたの次のステップ：マスタ登録スクリプト

あなたの用途だと、マスタ登録スクリプトは **ORM を使うと圧倒的に書きやすい**です。

例えば：

- products マスタ
- materials マスタ
- users マスタ

などを Excel や CSV から登録する場合、

```python
p = Product(product_code=row["product_code"], name=row["name"])
session.add(p)
```

のように書けるので、Core より直感的です。
