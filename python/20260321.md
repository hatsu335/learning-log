## [正規化]

材料名を英語、加工種類を日本語で運用する方針は、アプリの性質（作業者の視認性を重視しつつ、データ構造は堅牢にしたい）に非常に適しています。  
この前提で、**材料名と加工種類の正規化ルールを“実務で長く使える形”にまとめ直す**と、次のような体系が最も安定します。

---

### 材料名（英語）の正規化ルール  
材料名は今後、在庫管理・材料取り都合・材料変更などの中心になるため、**厳密な統一ルール**が必要です。

#### 1. 英字はすべて大文字に統一  
- ams-c-81986 → AMS-C-81986  
- sus304 → SUS304  

理由：  
- 大文字統一は工業規格で一般的  
- API や DB での比較が安定する  

#### 2. 記号はすべて半角に統一  
- “－” → “-”  
- “／” → “/”  
- “×” → “x”  

理由：  
- 全角記号は検索で一致しないことがある  
- Web 化したときに文字化けしやすい  

#### 3. 材料名のフォーマットを固定  
推奨フォーマット：

```
[材質]-[規格番号]
例：AMS-C-81986
```

理由：  
- 工業材料の一般的な表記  
- 材料名の構造が明確になり、検索しやすい  

#### 4. 材料寸法は “幅x高さx長さ” の半角統一  
```
100x50x2000
```

理由：  
- 数値比較がしやすい  
- Web API で扱いやすい  

#### 5. 略称は使わず正式名称に統一  
- “sus” → “SUS304”  
- “ams” → “AMS-C-81986”  

理由：  
- 略称は人によって揺れやすい  
- 長期運用で混乱が起きる  

---

### 加工種類（日本語）の正規化ルール  
加工種類は作業者が画面で見る項目なので、**読みやすさ・現場の慣習**を優先します。  
ただし、データとして扱うために最低限の統一は必要です。

#### 1. 全角カタカナを基本とする  
- ﾌﾟﾚｽ → プレス  
- ｽﾎﾟﾝｼﾞ → スポンジ  

理由：  
- 半角カナは文字化けしやすい  
- 現場の視認性が悪い  

#### 2. 記号は半角に統一  
- “＋” → “+”  
- “－” → “-”  

例：  
```
プレス+スポンジ ハーフ同時加工
```

理由：  
- 全角記号は検索で一致しない  
- DB での比較が不安定になる  

#### 3. 複合加工は「主加工 → 副加工 → 条件」の順に統一  
例：  
- プレス+スポンジ ハーフ同時加工  
- レーザー+曲げ  

理由：  
- 順序が変わると別物扱いになる  
- 工程管理で並び順が重要  

#### 4. スペースは半角スペースに統一  
- “スポンジ ハーフ同時加工”  
（全角スペースは使わない）

理由：  
- 全角スペースは見えづらく、検索で一致しない  

#### 5. 略称は使わず正式名称に統一  
- “PLS” → “プレス”  
- “SPG” → “スポンジ”  

理由：  
- 作業者が見て理解しやすい  
- データの揺れを防ぐ  

---

### 材料名（英語）と加工種類（日本語）を混在させるときの注意点  
この組み合わせは実務でよくありますが、次の点を守ると長期的に安定します。

- 材料名は **ID 管理**（materials テーブル）  
- 加工種類も **ID 管理**（process_types テーブル）  
- 表示名は日本語のまま  
- 内部処理は ID で行う  

こうすることで、  
- 名称変更しても壊れない  
- 表示は現場向けに日本語のまま  
- データは英語・日本語混在でも整合性が保てる  

という理想的な構造になります。

---

### 次に進むためのステップ  
正規化ルールが固まったので、次は次の作業に進めます。

1. orders.csv と products.csv から  
   - 材料名（英語）  
   - 加工種類（日本語）  
   を抽出  
2. 正規化ルールに従って整形(正規化マッピング)  
3. materials / process_types テーブルに登録  
4. orders / products の材料名・加工種類を ID に置き換える  

この流れで進めると、理解しながら確実に移行できます。

## [正規化マッピング]

- 辞書形式で正規化を定義
- pandas の `mapメソッド`を使用して置換関数を作成
- 別名で保存

```python
import pandas as pd

# 正規化マッピング pandasのmapメソッドで正規化
normalize_map = {
    "ﾌﾟﾚｽ ﾊｰﾌ無": "プレス ハーフ無",

def normalize_process_type(df, column_name='加工種類'):

    df[column_name] = df[column_name].map(normalize_map).fillna(df[column_name])

    return df

def normalize_material(df, column_name='材料名'):
    df[column_name] = (df[column_name]
                    .astype(str)
                    .str.strip() # 全角スペース -> 半角
                    .str.replace(" ", "　") # 前後の空白除去
                    .str.replace(r"\s+", " ", regex=True)) # スペース連続 -> 1個に
    df[column_name] = df[column_name].map(material_map).fillna(df[column_name])

products = pd.read_csv("masters/products.csv")
```

**マッピングするための詳細設定**  
- `.astype(str)`型を整える
- `.str.strip()`全角スペースを半角スペースに
- `.str.replace(" ", "　")`前後の空白除去
- `.str.replace(r"\s+", " ", regex=True)`スペースの連続を1個に矯正
- `.fillna(df[column_name])`一致しなければ元の値のまま

```python
def normalize_process_type(df, column_name='加工種類'):
    df[column_name] = (df[column_name]

                       .str.strip()
                       .str.replace(" ", "　")
                       .str.replace(r"\s+", " ", regex=True))
    df[column_name] = df[column_name].map(normalize_map).fillna(df[column_name])
    return df
```

## [ID付与]

```python
import pandas as pd
import mysql.connector

# database 接続
conn = mysql.connector.connect(
    host = "localhost",
    user = "user",
    password = "password",
    database = "database"
)

# database から process_types / materials を読み込み
process_types_df = pd.read_sql("select id, name from process_types", conn)
materials_df = pd.read_sql("select id, name from materials", conn)

# 正規化済み csv 読み込み
products = pd.read_csv("masters/products_normalized.csv")
orders = pd.read_csv("masters/orders_normalized.csv")
process_prices = pd.read_csv("masters/process_prices_normalized.csv")

# IDを付与する関数
def attach_ids(df, process_types_df, materials_df):
    df = df.merge(process_types_df, left_on="加工種類", right_on="name", how="left")
    df = df.rename(columns={"id": "process_type_id"})
    df = df.drop(columns=["name"])

    df = df.merge(materials_df, left_on="材料名", right_on="name", how="left")
    df = df.rename(columns={"id": "material_id"})
    df = df.drop(columns=["name"])
    
    return df
    
# products / orders に ID を付与
products_with_id = attach_ids(products, process_types_df, materials_df)
orders_with_id = attach_ids(orders, process_types_df, materials_df)

# process_prices に process_type_id を付与
process_prices_with_id = process_prices.merge(
    process_types_df, left_on="加工種類", right_on="name", how="left").rename(columns={"id": "process_type_id"}).drop(columns=["name"])

# MySQL にインポートしやすい形で保存(csv)
products_with_id.to_csv("masters/products_ready.csv", index=False)
orders_with_id.to_csv("masters/orders_ready.csv", index=False)
process_prices_with_id.to_csv("masters/process_prices_ready.csv", index=False)

print("ID 置換が完了しました。")
```

```python
from sqlalchemy import create_engine
import pandas as pd

# id を整数に

orders["process_type_id"] = orders["process_type_id"].astype("int64")


# datetime を文字列化して NaT を除去
```
