## [顧客の月別レンタル数]

### 

マイコード
```sql
SELECT
  ct.customer_id AS ct_id,
  ct.first_name AS f_name,
  ct.last_name AS l_name,
--   SUM(CASE WHEN DATE_FORMAT(r.rental_date, "%Y-%m") = "2005-05" THEN 1 ELSE 0 END) AS 2005_05,  <-- これでもOK
  SUM(CASE WHEN YEAR(r.rental_date) = 2005 AND MONTH(r.rental_date) = 05 THEN 1 ELSE 0 END) AS 2005_05,
  SUM(CASE WHEN YEAR(r.rental_date) = 2005 AND MONTH(r.rental_date) = 06 THEN 1 ELSE 0 END) AS 2005_06,
  SUM(CASE WHEN YEAR(r.rental_date) = 2005 AND MONTH(r.rental_date) = 07 THEN 1 ELSE 0 END) AS 2005_07,
  SUM(CASE WHEN YEAR(r.rental_date) = 2005 AND MONTH(r.rental_date) = 08 THEN 1 ELSE 0 END) AS 2005_08
FROM customer ct
JOIN rental r ON ct.customer_id = r.customer_id
GROUP BY ct.customer_id, ct.first_name, ct.last_name;
```

#### 改善案  
- `MONTH(r.rental_date) = 05`の値は`05`では無く`5`で良い
- `DATE_FORMAT()`を使って`DATE_FORMAT(r.rental_date, '%Y-%m') = '2005-05'`と書ける  
（ただしインデックスが効かなくなる可能性があるので、パフォーマンス重視ならこのままでもよい）
- 拡張性を重視するならば縦持ちにしてピボットしやすくする

---

改善案　縦持ちコード（拡張性重視）
```sql
SELECT
  ct.customer_id AS ct_id,
  ct.first_name AS f_name,
  ct.last_name AS l_name,
  DATE_FORMAT(r.rental_date, '%Y-%m') AS rental_month,
  COUNT(ct.customer_id) AS rental_count
FROM customer ct  
JOIN rental r ON ct.customer_id = r.customer_id
GROUP BY ct_id, f_name, l_name, rental_month;
```
