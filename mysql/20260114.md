## [店舗ごとのジャンル別売上ランキング]

### 店舗ごとの売り上げを横持ちで比較

```sql
WITH store_sales as (
  SELECT
    c.name as category,
    SUM(CASE WHEN i.store_id = 1 THEN amount ELSE 0 END) as store_1,
    SUM(CASE WHEN i.store_id = 2 THEN amount ELSE 0 END) as store_2
  FROM payment p
  JOIN rental r ON p.rental_id = r.rental_id
  JOIN inventory i ON r.inventory_id = i.inventory_id
  JOIN film_category fc ON i.film_id = fc.film_id
  JOIN category c ON fc.category_id = c.category_id
  GROUP BY c.category_id, c.name)
SELECT
  category,
  store_1,
  RANK() OVER (ORDER BY store_1 DESC) as s1_ranking,
  store_2,
  RANK() OVER (ORDER BY store_2 DESC) as s2_ranking
FROM store_sales
ORDER BY store_1 DESC;
```

### 縦持ちで比較

```sql
SELECT
  c.name AS category,
  i.store_id AS store,
  SUM(p.amount) AS sales
FROM payment p
JOIN rental r ON p.rental_id = r.rental_id
JOIN inventory i ON r.inventory_id = i.inventory_id
JOIN film_category fc ON i.film_id = fc.film_id
JOIN category c ON fc.category_id = c.category_id
GROUP BY c.name, i.store_id
ORDER BY c.name, i.store_id;
```

**横持ちの特徴**  
1. 見やすいが列が固定される
2. 店舗数が少なく、固定されているときによい

**縦持ちの特徴**
1. 拡張性が高い(Pythonなどでピボット(クロス集計)しやすい)
2. 店舗数や集計軸が変動する可能性があるとき
