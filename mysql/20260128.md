**改善コード1**  
`NOT LIKE '%Africa%'`を使う
```sql
SELECT
  code, 
  name, 
  region, 
  population, 
  headofstate, 
  LifeExpectancy,
  ROW_NUMBER() OVER (ORDER BY LifeExpectancy DESC) AS ranking
FROM country
WHERE LifeExpectancy > 0
  AND region NOT LIKE '%Africa%'
ORDER BY LifeExpectancy
LIMIT 30;
```

---

**改善コード2**  
`NOT IN (...)`を使う
```sql
SELECT
  code, 
  name, 
  region, 
  population, 
  headofstate, 
  LifeExpectancy,
  ROW_NUMBER() OVER (ORDER BY LifeExpectancy DESC) AS ranking
FROM country
WHERE LifeExpectancy > 0
  AND region NOT IN (
    'Eastern Africa', 'Central Africa', 'Western Africa',
    'Northern Africa', 'Southern Africa'
  )
ORDER BY LifeExpectancy
LIMIT 30;
```

---

**改善コード3**  
`continet`カラムを使う（カラムに気づかんかった）
```sql
SELECT
  code, 
  name, 
  region, 
  population, 
  headofstate, 
  LifeExpectancy,
  ROW_NUMBER() OVER (ORDER BY LifeExpectancy DESC) AS ranking
FROM country
WHERE LifeExpectancy > 0
  AND continent != 'Africa'
ORDER BY LifeExpectancy
LIMIT 30;
```

#### 好きなのは２、ベストは１、continentカラムに気づいていたら迷わず３
