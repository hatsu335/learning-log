### [CASE式]
**既存のコード体系を新しい体系に変換して集計する**
```SQL
select case pref_name
  when '徳島' then '四国'
  when '香川' then '四国'
  when '愛媛' then '四国'
  when '高知' then '四国'
  when '福岡' then '九州'
  when '佐賀' then '九州'
  when '長崎' then '九州'
  else 'その他' end as erea,
  sum(population)
from poptbl group by erea;
-- GROUP BY句の別名が使用できるのは MySQL PostgreSQL のみ
```

**異なる条件の集計を１つのSQLで行う**
```SQL
select
  pref_name as '県名',
  sum((case when sex = 1 then population else 0 end)) as '男',
  sum((case when sex = 2 then population else 0 end)) as '女'
from poptbl2 group by pref_name;
```
