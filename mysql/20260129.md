## [DISM,SFCをバッチファイルで起動]

### DISM -> SFC の順で起動し、ログファイルを残す

いちいちPowershell立ち上げて入力するのも面倒なのでバッチファイルで処理

SystemCheck_DISM_SFC.bat
```Bash
@echo off
setlocal

:: 管理者権限チェックと昇格
openfiles >nul 2>&1
if %errorlevel% neq 0 (
    echo [Check] 管理者権限で再起動しています...
    powershell -Command "Start-Process '%~f0' -Verb RunAs"
    exit /b
)

:: ============================================================
::  System Check DISM → SFC 連続実行
::  ※進捗は画面のみ、ログは結果のみ
:: ============================================================

:: ログ保存フォルダ
set LOGDIR=%~dp0Logs
if not exist "%LOGDIR%" mkdir "%LOGDIR%"

:: 日付・時刻をログファイル名に使用（YYYY-MM-DD_HHMM）
for /f "tokens=1-4 delims=/ " %%a in ('date /t') do (
    set YYYY=%%a
    set MM=%%b
    set DD=%%c
)
for /f "tokens=1-2 delims=: " %%a in ("%time%") do (
    set HH=%%a
    set MN=%%b
)

set LOGFILE=%LOGDIR%\Repair_%YYYY%-%MM%-%DD%_%HH%%MN%.log

echo ログ保存先: %LOGFILE%
echo ------------------------------------------------------------- >> "%LOGFILE%"
echo 実行日時: %YYYY%-%MM%-%DD% %HH%:%MN% >> "%LOGFILE%"
echo ------------------------------------------------------------- >> "%LOGFILE%"

echo.
echo === DISM を実行します ===
echo [DISM START] >> "%LOGFILE%"

:: 進捗は画面のみ
dism /online /cleanup-image /restorehealth > "%LOGDIR%\dism_tmp.log" 2>&1

:: 最終行だけログに追加
for /f "usebackq tokens=* delims=" %%l in ("%LOGDIR%\dism_tmp.log") do set LASTLINE=%%l
echo %LASTLINE% >> "%LOGFILE%"

del "%LOGDIR%\dism_tmp.log"
echo [DISM END] >> "%LOGFILE%"
echo.

echo === SFC を実行します ===
echo [SFC START] >> "%LOGFILE%"

sfc /scannow > "%LOGDIR%\sfc_tmp.log" 2>&1

for /f "usebackq tokens=* delims=" %%l in ("%LOGDIR%\sfc_tmp.log") do set LASTLINE=%%l
echo %LASTLINE% >> "%LOGFILE%"

del "%LOGDIR%\sfc_tmp.log"
echo [SFC END] >> "%LOGFILE%"
echo.

echo ------------------------------------------------------------- >> "%LOGFILE%"
echo 完了しました。 >> "%LOGFILE%"
echo -------------------------------------------------------------

echo 全処理が完了しました。
echo ログは Logs フォルダに保存されています。
pause
```

### DISM,SFCをそれぞれ単独で起動

状況に応じて単独で起動したい場合のそれぞれのバッチファイル

DISM.bat
```Bash
@echo off
:: 文字化けを防ぐためにUTF-8モードに切り替え
chcp 65001 >nul
setlocal

:: 管理者権限チェックと昇格
openfiles >nul 2>&1
if %errorlevel% neq 0 (
    echo [Check] 管理者権限で再起動しています...
    powershell -Command "Start-Process '%~f0' -Verb RunAs"
    exit /b
)

echo ================================
echo   DISM システムイメージの修復
echo ================================

echo DISM によるコンポーネントストア修復を開始します...
dism /online /cleanup-image /restorehealth

echo.
echo DISM の処理が完了しました。
pause
```

SFC.bat
```Bash
@echo off
:: 文字化けを防ぐためにUTF-8モードに切り替え
chcp 65001 >nul
setlocal

:: 管理者権限チェックと昇格
openfiles >nul 2>&1
if %errorlevel% neq 0 (
    echo [Check] 管理者権限で再起動しています...
    powershell -Command "Start-Process '%~f0' -Verb RunAs"

)

echo ======================================================
echo   System File Checker  整合性検査 破損ファイル修復
echo ======================================================

echo SFC スキャンを開始します...
sfc /scannow

echo.
echo SFC スキャンが完了しました。

```

## [world詳細（MySQL）]

## 1. テーブル定義（DDL）の詳細

各テーブルのカラム名、データ型、制約のまとめ  
特に**データ型（ENUMやDecimalなど）**や**主キー・外部キーの関係**に注目  

### ① country（国の情報）

もっとも情報量が多く、他2つのテーブルの親となるテーブル

| カラム名 | 型 | 制約・備考 |
| --- | --- | --- |
| **Code** | `CHAR(3)` | **主キー**。国コード（'JPN', 'USA'など） |
| **Name** | `CHAR(52)` | 国の名前 |
| **Continent** | `ENUM(...)` | 7大陸（'Asia', 'Europe'等）から選択 |
| **Region** | `CHAR(26)` | 地域区分（'Eastern Asia'など） |
| **SurfaceArea** | `DECIMAL(10,2)` | 表面積 |
| **IndepYear** | `SMALLINT` | 独立年 |
| **Population** | `INT` | 人口 |
| **LifeExpectancy** | `DECIMAL(3,1)` | 平均寿命 |
| **GNP / GNPOid** | `DECIMAL(10,2)` | 国民総生産 / 前年度のGNP |
| **LocalName** | `CHAR(45)` | 現地での名称 |
| **GovernmentForm** | `CHAR(45)` | 統治形態（'Republic'など） |
| **HeadOfState** | `CHAR(60)` | 国家元首 |
| **Capital** | `INT` | 首都のID（`city`テーブルのIDと紐付く） |
| **Code2** | `CHAR(2)` | 2文字の国コード（'JP', 'US'など） |

### ② city（都市の情報）

国に属する都市のデータ

| カラム名 | 型 | 制約・備考 |
| --- | --- | --- |
| **ID** | `INT` | **主キー**。自動連番（Auto Increment） |
| **Name** | `CHAR(35)` | 都市名（'Tokyo', 'New York'など） |
| **CountryCode** | `CHAR(3)` | **外部キー**。`country.Code` と紐付く |
| **District** | `CHAR(20)` | 行政区画（日本の場合は'Tokyo-to'や'Aichi'など） |
| **Population** | `INT` | 都市の人口 |

### ③ countrylanguage（言語の情報）

どの国で、どの言語が、どれくらいの割合で話されているかを示す

| カラム名 | 型 | 制約・備考 |
| --- | --- | --- |
| **CountryCode** | `CHAR(3)` | **主キー(1/2)**。`country.Code` と紐付く |
| **Language** | `CHAR(30)` | **主キー(2/2)**。言語名 |
| **IsOfficial** | `ENUM('T','F')` | 公用語かどうか（True / False） |
| **Percentage** | `DECIMAL(4,1)` | その言語を話す人の割合（%） |

### 人口が1億人以上の国を、人口が多い順に並べて表示

```sql
SELECT
  name, 
  continent, 
  region,
  lifeexpectancy,
  population,
  ROW_NUMBER() OVER (ORDER BY population DESC) AS ranking
FROM country
WHERE population >= 100000000
ORDER BY population DESC;
```

### 大陸ごとに、その大陸に属する国の数と平均寿命の平均などを算出

```sql
SELECT
  continent,
  COUNT(name) AS countries,
  ROUND(AVG(lifeexpectancy), 1) AS lifeexpectancy,
  SUM(population) AS population,
  ROUND(SUM(population) / (SELECT SUM(population) FROM country) * 100, 1) AS rate,
  ROUND(SUM(population) / SUM(surfacearea), 1) AS density
FROM country
GROUP BY continent
ORDER BY population DESC;
```

```sql
  co.name AS country,
  ci.name AS city,

  ci.population AS population,
  ROW_NUMBER() OVER (ORDER BY ci.population DESC) AS ranking
FROM country co
JOIN city ci ON co.code = ci.countrycode
```

### 公用語としてスペイン語が話されており、かつその割合が50%以上の国名と国家元首を表示

```sql
SELECT
  co.name AS country,
  co.continent AS continent,
  co.region AS region,
  cl.percentage AS rate,
  ROW_NUMBER() OVER (ORDER BY cl.percentage DESC) AS ranking,
  co.headofstate AS head_of_state
FROM country co
JOIN countrylanguage cl ON co.code = cl.countrycode  
WHERE cl.language = 'Spanish'
AND cl.isofficial = 'T'
AND cl.percentage >= 50
ORDER BY cl.percentage DESC;
```
