## [HTML/CSS環境作り]

### **VSCodeでHTML/CSSの環境作り（プラグインインストール）**

### 必須レベル（入れておくと絶対便利）

| プラグイン名 | 説明 |
|--------------|------|
| **Live Server** | HTMLを保存するたびにブラウザで自動リロードしてくれる。リアルタイムプレビューの定番！ |
| **Prettier – Code formatter** | HTML/CSS/JSのコードを自動整形してくれる。インデントやスペースがきれいに揃う |
| **Emmet（標準搭載）** | `div.container>ul>li*3` → 自動でHTML展開！VS Codeに最初から入ってるけど超重要 |
| **HTML CSS Support** | HTMLファイル内で書いたクラス名に対して、CSSの補完をしてくれる |
| **CSS Peek** | HTMLのクラス名から対応するCSS定義へジャンプできる（Ctrl+クリック） |


### あったら嬉しい便利系（作業が快適に）

| プラグイン名 | 説明 |
|--------------|------|
| **Auto Rename Tag** | 開始タグを変更すると、終了タグも自動で変わる（例：`<div>` → `<section>`） |
| **IntelliSense for CSS class names in HTML** | HTML内でCSSクラス名を補完してくれる（特に外部CSSファイルを使うときに便利） |
| **Color Highlight** | CSSの色コード（#ff0000など）を色付きで表示してくれる。視覚的にわかりやすい！ |
| **Live Sass Compiler** | Sass（SCSS）を使うなら必須。保存時に自動でCSSに変換してくれる |
| **Path Intellisense** | 画像やCSSファイルのパスを補完してくれる。地味だけど超便利！ |


### ちょっと上級だけど面白い系

| プラグイン名 | 説明 |
|--------------|------|
| **Tailwind CSS IntelliSense** | Tailwind CSSを使うなら必須。クラス補完やドキュメント表示が超強力 |
| **Thunder Client** | APIのテストができるPostman風ツール。JavaScriptと連携するなら便利！

## 問題：競合が原因と思われる`Ctrl + /`でコメントアウトできない不具合

### **解決方法**  

`keybindings.json`に直接追加  

1. コマンドパレット(`Ctrl + Shift + P`)で「Preferences: Open Keyboard Shortcuts(JSON)」を開く
1. 以下のコードを追加して保存

```json
{
  "key": "ctrl+/",
  "command": "editor.action.commentLine",
  "when": "editorTextFocus && !editorReadonly"
}
```

## [HTML]

### HTMLとは

**HTML文とは、あくまでもブラウザや検索エンジンなどのコンピュータがこの文書の意味を解析しやすいように、**  
**文書の意味ごとにわかりやすい区切りをつけている記述なので、見た目を気にするものではない**

例：`<section>`などは文書の意味ごとに分かりやすく区切るためのタグだが、ブラウザで見ると何も変化はない  

### 今日学んだHTML構文
1. ファイル名は`index.html`
1. html:5  雛形を出してくれる
1. `<h1>`  見出し  Heading
1. `<p>`   段落    Paragraph
1. `<img>` 画像    Image
   1. src 属性   Source  画像ファイル名の指定
   1. alt 属性           テキスト表示・音声読み上げなどの補助
   1. width              ピクセルで横サイズ指定(単位の`px`は不要)
   1. height             ピクセルで縦サイズ指定(単位の`px`は不要)
1. リスト
   1. `<ul>` `<li>`       箇条書きリスト
   1. `<lo>` `<li>`       順序付きリスト
   1. `<dl>` `<dt>` `<dd>`  説明付きリスト
1. 表の表現
   1. `<table>`         全体
   1. `<thead>` `<tbody>` 見出し/本体
   1. `<tr>`            行
   1. `<th>` `<td>`       セル
1. リンク
   1. `<a>`    リンク   Anchor
      1. href   属性     アドレスを指定
      1. target 属性     `_bland`を指定すると別タグを開く
1. `<section>`    文書の意味事に分かりやすい区切りをつける

---

コード
```html
<!DOCTYPE html>              <!-- 最初に"HTML:5"と入力すると雛形が表示される -->
<html lang="ja">             <!-- 言語: 日本語 -->
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <!-- <img>タグには終了タグは無い  サイズの単位はピクセル(pタグの文字の標準が16pxと覚えているとわかりやすい) -->
    <!-- <img>タグにサイズを指定する目的は、読み込み時に表示領域を確保してレイアウトのガタつきを抑えるため(他のタグではCSSで指定するのが普通) -->
    <img src="logo.png" alt="ロゴ画像" width="160" height="160">

    <h1>アニマルハウス</h1>

    <section>
        <h2>サービスの特徴</h2>
        <p>変わった人たちを派遣しています。様々な特技や容姿で楽しめます。</p>        <!-- pタグの文字の大きさは16px(default size) -->
    </section>

    <section>
        <h2>提供中のプラン</h2>
        <p>次のようなプランを提供中です。</p>
        <!-- 3種類のリスト表現 -->
        <!-- 箇条書きリスト: タグは <ul>(Unordered List)、項目は <li>(List Item)で囲む-->
        <ul>
            <li>家事手伝い</li>
            <li>庭掃除</li>
            <li>犬のさんぽ</li>
        </ul>
        <!--順序付きリスト: タグは <ol>(Ordered List)、項目は <li>(List Item)で囲む-->
        <ol>
            <li>家事手伝い</li>
            <li>庭掃除</li>
            <li>犬のさんぽ</li>
        </ol>
        <!--説明付きリスト: タグは <dl>(Description List)、項目は <dt>(Description Term)、説明は <dd>(Description Details)で囲む-->
        <dl>
            <dt>家事手伝い</dt>
            <dd>料理からお掃除まで</dd>
            <dt>庭掃除</dt>
            <dd>芝刈りから剪定まで</dd>
            <dt>犬のさんぽ</dt>
            <dd>相性によってお受けできない可能性があります</dd>
        </dl>
    </section>

    <section>
        <h2>サービスの沿革</h2>
        <p>サービスの沿革は以下の通りです。</p>
        <!-- 表の表現方法 -->
        <!-- 1.全体        <table></table> -->
        <!-- 2.見出し/本体 <thead></thead> / <tbody></tbody>   thead(Table head) tbody(Tabale body)-->
        <!-- 3.行         <tr></tr>                           tr(Table row)-->
        <!-- 4.セル       <th></th> と <td></td>               th(Table header) td(Table data cell)-->
        <!-- リンク       <a href="http://yahoo.co.jp"></a>    href(Hypertext reference) ウェブページへのレファレンス(参照)-->
        <!-- リンク(別タグを開く)  <a href="http://yahoo.co.jp" target="_blank"></a>    target="_blank"を挿入することで別タグを開く -->
        <table>
            <thead>
                <tr><th>年</th><th>出来事</th></tr>
            </thead>
            <tbody>
                <tr>
                    <td>2020</td>
                    <td>家事手伝いサービス開始</td>
                </tr>
                <tr>
                    <td>2022</td>
                    <td><a href="http://yahoo.co.jp" target="_blank">犬のさんぽサービス開始</a></td>
                </tr>
            </tbody>
        </table>
    </section>
</body>
</html>
```
