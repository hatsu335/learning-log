コード
```sql
SELECT
  AVG(CASE WHEN shohin_bunrui = '衣服' THEN hanbai_tanka - shiire_tanka
  ELSE NULL END) AS '衣服',
  AVG(CASE WHEN shohin_bunrui = '事務用品' THEN hanbai_tanka - shiire_tanka
  ELSE NULL END) AS '事務用品',
  AVG(CASE WHEN shohin_bunrui = 'キッチン用品' THEN hanbai_tanka - shiire_tanka
  ELSE NULL END) AS 'キッチン用品'
FROM
  shohin;
```

## [ネットワーク設定とシステムインストール]

### セキュリティ強化のため社内ネットワークの再構築  
経緯は以下の通り  
1. 内部が壊れていて`DISM`が機能しないため、バージョンの合う`ISO`ファイルを用意して修復
1. `24H2`から`25H2`へアップグレードしてなおかつリセットして初期状態に
1. 元のIPアドレスを使用してネットワーク設定終了

知る限りでは間違いなく設定を終えて無事ネットワークに繋がるはずだったが繋がらない  
結果としてはIPアドレスを変更してうまくいった  

### 問題の原因と思われるもの  
社内のネットワークではアライドテレシス製のイーサネットスイッチがほとんどのため、  
IPアドレス情報をもっている可能性が高い、よって実際に割り振っているIPアドレスは  
競合をしていないが、イーサネットスイッチに残っている情報が競合した可能性が高い  
今後も初期設定からやり直す場合はIPアドレスも変更した方が良いと思われる  

### システムインストール  
セキュリティを強化したため従来の方法でインストールがはじかれた  
回避方法は以下の通り  
- `Windows Defender`を一時的にOFF(ウイルスと脅威の防止の設定の中のリアルタイム保護をOFF)
- グループポリシーの「ネットワーククライアント:常に通信にデジタル署名を行う」を無効にする
- 両方の設定を元に戻して終了
