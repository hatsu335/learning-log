## [俳優の映画出演数のベスト5]

### マイコード
```sql
SELECT
  COUNT(actor_id) as film_id,
  first_name,
  last_name
FROM (select
  actor.actor_id,
  actor.first_name,
  actor.last_name,
  film_actor.film_id
FROM actor JOIN film_actor
ON actor.actor_id = film_actor.actor_id) as sub
group by actor_id
ORDER BY film_id DESC LIMIT 5;
```

良かった点  
- `JOIN`で`actor`と`film_actor`を正しく結合している
- `COUNT(acotr_id)`で出演数をカウント
- `GORUP BY actor_id`で俳優ごとに集計

改善点  
- `COUNT(actor_id)`でも動くが`COUNT(film_id)`の方が「出演した映画の数」という意図が明確になる
- サブクエリを使わなくても、直接`JOIN`して`GROUP BY`すれば同じ結果を得られる

### 改善後のクエリ
```SQL
SELECT
  a.actor_id,
  a.first_name,
  a.last_name,
  COUNT(fa.film_id) AS film_count
FROM actor a
JOIN film_actor fa ON a.actor_id = fa.actor_id
GROUP BY a.actor_id, a.first_name, a.last_name
ORDER BY film_count DESC
LIMIT 5;
```
補足  
- `GROUP BY`に`first_name`と`last_name`を含めたのは、SQLの標準仕様に沿うため
- `film_count`という別名にしておくと、後で読みやすいので他の集計と組み合わせるときに便利

## [俳優の映画出演数のベスト10を抽出してランキングを入れる]

### マイコード  
上記コードのSELECT文に一行追加  
```SQL
SELECT
  a.actor_id,
  a.first_name,
  a.last_name,
  count(f.film_id) as film_count,
  row_number() over (order by (count(f.film_id)) desc) as ranking  <- ここ
```
注意点(`ROW_NUMBER()`の使い方)  

集計関数をウィンドウ関数の中で直接使うのはNG  
一応MySQLで動いたが、意図しない結果になる可能性がある  
改善案としてはサブクエリで集計してから`ROW_NUMBER()`を使う  

### 改善コード  
```SQL
SELECT
  actor_id,
  first_name,
  last_name,
  film_count,
  ROW_NUMBER() OVER (ORDER BY film_count DESC) AS ranking
FROM (
  SELECT
    a.actor_id,
    a.first_name,
    a.last_name,
    COUNT(f.film_id) AS film_count
  FROM actor a
  JOIN film_actor f ON a.actor_id = f.actor_id
  GROUP BY a.actor_id, a.first_name, a.last_name
) AS sub
ORDER BY film_count DESC
LIMIT 10;
```

## [出演数トップ俳優のカテゴリー別出演数(多段JOIN)]

### マイコード

```sql
SELECT
  category_id,
  name,
  category_count
FROM (
  SELECT
    c.category_id,
    c.name,
    count(c.category_id) as category_count
  FROM film_actor as fa  
  JOIN film_category as fc on fa.film_id = fc.film_id
  JOIN category as c on fc.category_id = c.category_id
  WHERE fa.actor_id = 107
  GROUP BY c.category_id, c.name
) as sub
ORDER BY category_count DESC;
```

良かった点  
- `film_actor`->`film_category`->`category`のJOINの流れは完璧
- `WHERE fa.actor_id = 107`で対象の俳優を絞っている
- `GROUP BY`でジャンルごとの出演数を集計

改善点  
- サブクエリ不要
- 俳優名を入れる

### 改善コード

```sql
SELECT
  a.first_name,
  a.last_name,
  c.name as category_name,
  count(c.category_id) as category_count
FROM category as c  
JOIN film_category as fc ON c.category_id = fc.category_id
JOIN film_actor as fa ON fc.film_id = fa.film_id
JOIN actor as a ON fa.actor_id = a.actor_id
WHERE a.actor_id = 107
GROUP BY c.category_id, c.name
ORDER BY category_count DESC;
```
