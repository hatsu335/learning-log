  SUM(likes) OVER w AS gr_sum

  posts

  w

### [活性化関数]
**隠れ層の活性化関数を変えると、学習のスピードや精度、勾配消失の影響が大きく変わる。以下に代表的な関数とその特徴**

**1.Sigmoid関数**

$\sigma(x) = \frac{1}{1 + e^{-x}}$
- 特徴：出力が0〜1。勾配消失しやすい。
- 向いているケース：出力層（確率として解釈したいとき）
```python
lambda x: 1 / (1 + np.exp(-x))  # Sigmoid

lambda y: y * (1 - y)  # Sigmoidの導関数(微分)
```

**2.Tanh関数**

$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
- 特徴：出力が-1〜1。Sigmoidより中心が0で学習しやすい。
- 向いているケース：隠れ層に使うと安定しやすい
```python
lambda x: np.tanh(x)  # Tanh

lambda x: 1.0 - np.tanh(x) ** 2  # Tanhの導関数(微分)
```

**3.RuLU関数**

$\max(0, x)$
- 特徴：計算が速く、勾配消失しにくい。負の値は0になる。
- 向いているケース：深層ネットワークの隠れ層に最もよく使われる
```python
lambda x: np.maximum(0, x)  # ReLU

lambda x: (x > 0).astype(float)  # ReLUの導関数(微分)
```

**4.Leaky ReLU関数**

$x$ if $x > 0$ else $\alpha x$
- 特徴：ReLUの改良版。負の値も少し通す。
- 向いているケース：ReLUの「死んだニューロン」問題を回避したいとき
```python
lambda x: np.where(x > 0, x, 0.01 * x)  # Leaky ReLU

lambda x: np.where(x > 0, 1.0, 0.01)  # Leaky ReLUの導関数(微分)
```

**CupyベースからNumpyベースのコードへ改造の過程で活性化関数もテスト**  
※Cupyベースで構築したが、MNISTデータセットではGPUにたよるまでもなかった
```
活性化関数の選び方と違い

- **隠れ層**：`ReLU` または `tanh`  
  → 勾配消失を防ぎつつ、学習を早く安定させたいなら `ReLU` が第一候補。  
  → 小規模ネットワークや滑らかさを重視するなら `tanh` もアリ。

- **出力層**：`sigmoid`（今のままでOK）  
  → 出力が0〜1の範囲になるので、MNISTのような**多クラス分類**では、**softmax**も選択肢になる。
```

ReLUを隠れ層に使うコード例（NumPyベース）  
隠れ層にReLUを使い、出力層にSigmoidを使うように変更したNeuralNetwork本体コード例

```Python
import numpy as np

class NeuralNetwork:
    def __init__(self, inputnodes, hiddennodes, outputnodes, learningrate):
        self.inodes = inputnodes
        self.hnodes = hiddennodes
        self.onodes = outputnodes
        self.lr = learningrate

        self.wih = np.random.normal(0.0, pow(self.inodes, -0.5), (self.hnodes, self.inodes))
        self.who = np.random.normal(0.0, pow(self.hnodes, -0.5), (self.onodes, self.hnodes))

        # 活性化関数
        self.hidden_activation = lambda x: np.maximum(0, x)  # ReLU
        self.hidden_derivative = lambda x: (x > 0).astype(float)  # ReLUの導関数

        self.output_activation = lambda x: 1 / (1 + np.exp(-x))  # Sigmoid
        self.output_derivative = lambda y: y * (1 - y)  # Sigmoidの導関数（出力を使う）

    def train(self, inputs_list, targets_list, epoch):
        inputs = np.array(inputs_list, ndmin=2).T
        targets = np.array(targets_list, ndmin=2).T

        hidden_inputs = np.dot(self.wih, inputs)
        hidden_outputs = self.hidden_activation(hidden_inputs)

        final_inputs = np.dot(self.who, hidden_outputs)
        final_outputs = self.output_activation(final_inputs)

        output_errors = targets - final_outputs
        hidden_errors = np.dot(self.who.T, output_errors)

        self.who += self.lr ** (epoch + 1) * np.dot((output_errors * self.output_derivative(final_outputs)), hidden_outputs.T)
        self.wih += self.lr ** (epoch + 1) * np.dot((hidden_errors * self.hidden_derivative(hidden_inputs)), inputs.T)

    def query(self, inputs_list):
        inputs = np.array(inputs_list, ndmin=2).T
        hidden_inputs = np.dot(self.wih, inputs)
        hidden_outputs = self.hidden_activation(hidden_inputs)
        final_inputs = np.dot(self.who, hidden_outputs)
        final_outputs = self.output_activation(final_inputs)
        return final_outputs
```

## 補足

| 隠れ層の関数 | 学習速度 | 精度 | 傾向 |
|---------------|----------|------|------|
| Sigmoid       | 遅め     | 安定 | 勾配消失に注意 |
| Tanh          | 中程度   | 安定 | 中心が0で学習しやすい |
| ReLU          | 速い     | 高精度 | 深層学習で定番。死んだニューロンに注意 |
| Leaky ReLU    | 速い     | 安定 | ReLUの改良版で安定性あり |

## VSCodeにおける警告対処
Pylanceの影響でデータ読み込みの際の np.frombuffer に対して引数の不整合の疑いで警告が出る  
gzip.open(...).read(...) の戻り値の型が bytes であると推論できていないことが原因  
実行には問題はないが気持ち悪いので対処  

解決方法：cast で明示的に型を指定する  

問題コード
```python
def targets_file(filename):
    with gzip.open(filename, 'rb') as f:
        _magic, total_label = struct.unpack('>II', f.read(8)) # cast(bytes, f.read...) に変更
        label_data = f.read(total_label) # cast(bytes, f.read...) に変更
        labels = np.frombuffer(label_data, dtype=np.uint8) # ここで警告発生
        return np.asarray(labels)
```
修正コード
```python
from typing import cast  # モジュール追加

def targets_file(filename):
    with gzip.open(filename, 'rb') as f:
        _magic, total_label = struct.unpack('>II', cast(bytes, f.read(8))) # 型を指定する
        label_data = cast(bytes, f.read(total_label)) # 型を指定する
        labels = np.frombuffer(label_data, dtype=np.uint8)
        return np.asarray(labels)
```
