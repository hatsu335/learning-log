## [EXISTS / NOT EXISTS]

### NOT EXISTS を使うべき典型判断基準

以下に当てはまれば **NOT EXISTS を選ぶ**べき

* 「一度も〜されていない」
* 「該当レコードが存在しない」
* 「1件でもあったら除外」

---

### 在庫の無いDVD一覧  
`NOT EXISTS`
```sql
SELECT
  f.film_id,
  f.title,
  ROW_NUMBER() over(ORDER BY f.film_id) as row_num
FROM film as f
WHERE NOT EXISTS(
    SELECT 1
    FROM inventory i
    WHERE f.film_id = i.film_id
);
```

---

### 在庫はあるが一度も借りられていないDVD一覧  
`EXISTS` + `AND` + `NOT EXISTS`
```sql
SELECT
  f.film_id,
  f.title,
  ROW_NUMBER() OVER (ORDER BY film_id) as row_num  
FROM film f 
WHERE EXISTS (
    SELECT 1
    FROM inventory i
    WHERE f.film_id = i.film_id
    AND NOT EXISTS (
        SELECT 1
        FROM rental r
        WHERE i.inventory_id = r.inventory_id
    )
);
```

---

### filmテーブルの中からレンタル実績の無い映画のタイトル一覧
`NOT EXISTS` + `JOIN`
```sql
SELECT
  f.film_id,
  f.title,
  ROW_NUMBER() OVER (ORDER BY film_id) AS row_num  
FROM film f 
WHERE NOT EXISTS (
    SELECT 1
    FROM inventory i 
    JOIN rental r ON i.inventory_id = r.inventory_id
    WHERE f.film_id = i.film_id
);
```

## [sakila 詳細]

MySQL の **sakila スキーマ**は、「DVD レンタル業務」を想定した **実務寄りの正規化済みデータベース**  
**役割・関係・業務上の意味**を理解することが重要



1. **テーブル全体構成（分類）**
2. **各テーブルの詳細（役割・主なカラム・関連）**

---

## 1. sakila テーブル全体構成（分類）

sakila のテーブルは大きく **6 系統**に分かれます。

| 分類     | 内容            |
| ------ | ------------- |
| マスタ系   | 映画・俳優・言語・ジャンル |
| 在庫・店舗系 | 店舗・在庫・スタッフ    |
| 顧客系    | 顧客・住所・国・都市    |
| レンタル系  | レンタル履歴        |
| 売上系    | 支払い           |
| 補助系    | 多対多関係・正規化補助   |

---
