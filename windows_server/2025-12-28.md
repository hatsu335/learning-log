### [TCP/IPの仕組み]
**TCP/IPの構造は5層に分かれている**
- アプリケーション層 (HTTP, SMTP, POP3, FTP, TELNET, NNTP, RCP...)
- トランスポート層   (TCP, UDP   powsershellから netstat や netstat -a から確認できる)
- ネットワーク層     (IP)
- データリンク層     (Ethenet, FDDI, ATM, PPP, PPPoE...)
- 物理層

以下のコマンドでほとんどの情報が得られる
```powershell
ipconfig /all
```

通信ができているか確認(アドレス部をIPアドレスにしてもOK)
```Powershell
ping www.yahoo.co.jp
```

> パケット通信の仕組み、ポート、サブネットマスクなど知りたかったことが盛りだくさん
