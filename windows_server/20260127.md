## [CheckNetwork_v4.bat]

### PC設定取得スクリプト（バッチファイル）改定版

管理者モードで起動してPCの設定をファイルに出力  
Geminiなどを利用して設定の問題点など診断してもらう  
各PCごとに診断内容に応じて処置をこころみる  

1. デスクトップパスをPowershell経由で取得
1. 保存先を確認
1. セキュリティ設定を取得
1. ネットワーク詳細を取得
1. グループポリシーを取得
1. レジストリ設定を取得
1. 追加のネットワーク診断情報を取得
1. デスクトップへ「PC_Config_Report.txt」で保存
1. 共有設定が有効か確認するコマンド例(追加項目)

CheckNetwork_v4.bat
```Bash
@echo off
:: 文字化けを防ぐためにUTF-8モードに切り替え
chcp 65001 >nul
setlocal

:: 管理者権限チェックと昇格
openfiles >nul 2>&1
if %errorlevel% neq 0 (
    echo [Check] 管理者権限で再起動しています...
    powershell -Command "Start-Process '%~f0' -Verb RunAs"
    exit /b
)

echo ========================================
echo   PC設定取得スクリプト (Network Check)
echo ========================================

:: デスクトップパスをPowerShell経由で取得
for /f "usebackq delims=" %%a in (`powershell -NoProfile -Command "[System.Environment]::GetFolderPath('Desktop')"`) do set "DESKTOP=%%a"
set "OUT_FILE=%DESKTOP%\PC_Config_Report.txt"

echo [1/4] 保存先を確認: %OUT_FILE%

:: レポート作成開始（最初だけ新規作成、後は追記）
echo --- PC Configuration Report --- > "%OUT_FILE%"

echo [2/4] セキュリティ設定を取得中...
powershell -NoProfile -Command "Get-MpComputerStatus" >> "%OUT_FILE%" 2>&1

echo [3/4] ネットワーク詳細を取得中...
powershell -NoProfile -Command "Get-NetIPConfiguration -All" >> "%OUT_FILE%" 2>&1

echo [4/4] グループポリシーを取得中 (数秒かかります)...
gpresult /r >> "%OUT_FILE%" 2>&1

echo [*] レジストリ設定を追記中...
powershell -NoProfile -Command "Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters'" >> "%OUT_FILE%" 2>&1
powershell -NoProfile -Command "Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings'" >> "%OUT_FILE%" 2>&1
echo [*] 追加のネットワーク診断情報を取得中...
echo --- Routing Table --- >> "%OUT_FILE%"
route print >> "%OUT_FILE%" 2>&1

echo --- Hosts File --- >> "%OUT_FILE%"
type C:\Windows\System32\drivers\etc\hosts >> "%OUT_FILE%" 2>&1

echo --- Interface Metrics --- >> "%OUT_FILE%"
powershell -NoProfile -Command "Get-NetIPInterface | Select-Object InterfaceAlias, AddressFamily, InterfaceMetric, ConnectionState | Sort-Object InterfaceMetric" >> "%OUT_FILE%" 2>&1

:: 共有設定が有効か確認するコマンド例
powershell -NoProfile -Command "Get-SmbServerConfiguration | Select-Object EnableSMB1Protocol, EnableSMB2Protocol" >> "%OUT_FILE%"
powershell -NoProfile -Command "Get-NetFirewallRule -DisplayGroup 'ファイルとプリンターの共有*' | Select-Object Name, Enabled, Profile" >> "%OUT_FILE%"

echo.
echo ----------------------------------------
echo 完了しました！
echo デスクトップの「PC_Config_Report.txt」を開いてください。
echo ----------------------------------------
pause
```

## [ResultConfig.bat]

### グループポリシーの初期化

管理者モードで起動してグループポリシーを初期化する  
実行後に`ネットワークのリセット`を手動で行い完全にクリアな状態へ戻してから各種設定を行う  
リセット後はIPアドレスは自動取得設定になる  

ResultConfig.bat
```Bash
@echo off
echo --- Resetting Group Policy ---
RD /S /Q "%WinDir%\System32\GroupPolicyUsers"
RD /S /Q "%WinDir%\System32\GroupPolicy"
gpupdate /force

echo --- Opening Network Reset Screen ---
control /name Microsoft.NetworkAndSharingCenter

echo.
echo Please run "Network Reset" manually from the Settings window.
echo The PC will restart in 5 minutes after execution.
pause
```

### 【その後の設定】  

**グループポリシー変更**  
- 「安全ではないゲストログオンを有効にする」 -> 「無効」に設定
- 「ネットワークセキュリティ: LAN Manager 認証レベル」 -> 「NTLMv2応答のみ送信する」に設定

**ネットワークプロファイルの変更**  
- プライベートネットワークに設定

**Windows Defender の設定**  
- ランサムウェアの防止 -> ON
- スマートアプリコントロール -> できればオン、できれば評価、オフでも止む無し
- 評価ベースの保護 -> ALLオン ※パスワード再利用の警告、パスワードの安全でない保存の警告のチェックは外し  
- コア分離 -> できればオン
- BitLocker -> めんどそうなので無効

**その他のセキュリティソフト**
- すべてアンインストール

### 状況に応じて`DISM`、`SFC`、`再インストール`を行い、ネットワークとPCともにクリーンアップを行いセキュリティも高める

最終的には`Server`や`NAS`は固定IPアドレスを割り振って、  
`クライアントPC`はIPアドレスを自動取得に設定した  

デフォルトゲートウェイが`192.168.1.1`に対してグループのIPアドレスが`192.168.0.x`だった為  
本来であればルーターの設定を変更して、サブネットマスクを`255.255.255.0`から  
`255.255.254.0`にしたかったが無念の断念(回線工事担当者パスワード等わからず)  
人任せ、業者任せはいいが責任まで人任せの者が一人からむとこうなる  
が、クライアントPCのIPアドレスを自動取得にすることでなんとか落ち着きそう  
クライアントPC間は`NAS`と`クラウド`を利用するスタイルに変更  

現段階においてはかなりのセキュリティの強化を実現  
あとは個人のITリテラシーの向上のみ
