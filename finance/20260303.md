## [yfinanceモジュール]

### 1. インストール

まずは、Pythonの環境で `yfinance` をインストールします。コマンドライン（ターミナルやコマンドプロンプト）で以下のコマンドを実行してください。

```bash
pip install yfinance

```

### 2. 基本的なデータの取得方法

Pythonのコードでドル/円（USD/JPY）のデータを取得する基本形です。

```python
import yfinance as yf

# 1. ティッカーシンボルの指定（FXのドル/円は "USDJPY=X"）
ticker = "USDJPY=X"

# 2. データのダウンロード（期間：直近1ヶ月、間隔：1日足）
# period: 1d, 5d, 1mo, 3mo, 6mo, 1y, 2y, 5y, 10y, ytd, max
# interval: 1m, 2m, 5m, 15m, 30m, 60m, 90m, 1h, 1d, 5d, 1wk, 1mo, 3mo
df = yf.download(ticker, period="1mo", interval="1d")

# 3. データの表示（最初の5行）
print(df.head())

```

### 3. 主なパラメータと取得できるデータ

`yf.download()` に渡す引数で、欲しいデータを自由にカスタマイズできます。

* **Ticker (銘柄名):**
* FX: `USDJPY=X`, `EURJPY=X`, `GBPJPY=X` など
* 日本株: `7203.T`（トヨタ）, `9984.T`（ソフトバンクG） ※末尾に `.T` をつける


* **Period (期間):**
* `1y`（1年分）、`max`（全期間）など。


* **Interval (時間軸):**
* `1m`（1分足）、`1h`（1時間足）、`1d`（日足）など。
* **注意:** `1m` や `5m` などの細かい時間足は、取得できる過去期間が短く制限されています（1分足なら過去7日間分など）。



### 4. 取得したデータを可視化する（おまけ）

グラフ描画ライブラリ `matplotlib` を使えば、取得したデータをすぐにチャートにできます。

```python
import matplotlib.pyplot as plt

# 終値（Close）をプロット
df['Close'].plot(figsize=(10, 5))
plt.title("USD/JPY Price Chart")
plt.grid()
plt.show()

```

### 注意点：自動売買に使う際の留意事項

`yfinance` は非常に便利ですが、以下の点には気をつけてください。

1. **データのラグ:** リアルタイムと謳っていますが、実際には数秒〜数分の遅延があると言われています。秒単位のスキャルピングには向きません。
2. **アクセスの制限:** 短時間に何千回もリクエストを送ると、Yahoo!側から一時的にIPアドレスをブロックされることがあります。
3. **不連続性:** 稀にデータが欠損していたり、異常な値が入っていたりすることがあります。本格的な運用前にはデータのクリーニング（異常値の除去）が必要です。

## [Anacondaを利用するうえでの推奨される手順（使い分け）]

### 1. なぜ「conda install」ではなく「pip」が推奨されるのか

実は、`yfinance` は公式には **PyPI (Python Package Index)** というリポジトリで管理されているパッケージであり、Anaconda専用（Condaレポジトリ）のパッケージではありません。

* **conda install yfinance:** Anacondaがコミュニティ（conda-forgeなど）から探してインストールしてくれます。便利ですが、Anaconda専用に調整されているわけではないため、時々「インストールはできたけど、バージョンが極端に古い」といった現象が起こることがあります。
* **pip install yfinance:** 公式開発者が配布している最新版を直接取得するため、常に最新の状態を保ちやすくなります。

### 2. Anacondaで正しくインストールする手順

Anacondaの環境内で `pip` を使う場合は、以下のように入力するのが最も確実です。

```bash
# ターミナル（またはAnaconda Prompt）で実行
pip install yfinance

```

**ポイント:** Anaconda環境の中に `pip` コマンドが既に含まれているため、`conda` 環境をアクティベートした状態でこのコマンドを打てば、その環境内に正しく `yfinance` がインストールされます。

### 3. もし「conda install」してしまった場合

すでに `conda install yfinance` を実行済みであれば、**そのまま使っていただいて全く問題ありません。** 動作に支障があるケースは極めて稀です。

もし今後、`yfinance` でエラーが出るようになったり、最新機能を使いたくなった場合は、以下の手順で「pip版」に上書きインストールしてください。

```bash
# condaで入れたものを無視して、pipで最新版を入れる
pip install --upgrade yfinance

```

### 補足：環境を綺麗に保つコツ

Anacondaでいろいろなライブラリを入れると、たまに依存関係（ライブラリ同士のバージョン相性）でエラーが出ることがあります。その際は、以下のコマンドで現在の環境を確認できます。

* `conda list`：今その環境に入っているライブラリの一覧を表示します。ここで `yfinance` がどこからインストールされたか（conda経由かpip経由か）を確認できます。

## [バックテスト]

Pythonでバックテストを行うには、取得した時系列データ（DataFrame）に対して「もしこの条件なら買う/売る」という判定を1行ずつループ、あるいは一括計算で当てはめていきます。

ここでは、最も基本的かつ有名な**「移動平均線（SMA）のゴールデンクロス・デッドクロス」**を使ったバックテストのコードを紹介します。

---

### 1. バックテストのサンプルコード

このコードでは、短期移動平均線が長期移動平均線を上に抜けたら買い、下に抜けたら売るというシミュレーションを行います。

```python
import yfinance as yf
import pandas as pd
import matplotlib.pyplot as plt

# 1. データの取得（ドル/円の過去2年分の日足）
ticker = "USDJPY=X"
df = yf.download(ticker, period="2y", interval="1d")

# 2. テクニカル指標（移動平均線）の計算
df['SMA_short'] = df['Close'].rolling(window=20).mean() # 20日移動平均
df['SMA_long'] = df['Close'].rolling(window=50).mean()  # 50日移動平均

# 3. 売買サインの判定
# 短期が長期を上回っていれば1（買い保持）、そうでなければ0
df['Signal'] = 0.0
df.loc[df['SMA_short'] > df['SMA_long'], 'Signal'] = 1.0

# 4. 戦略の収益率を計算
# 前日からの価格変化率に、前日のサイン（1か0か）を掛ける
df['Market_Return'] = df['Close'].pct_change()
df['Strategy_Return'] = df['Market_Return'] * df['Signal'].shift(1)

# 5. 累積収益率（資産の推移）を計算
df['Cumulative_Market'] = (1 + df['Market_Return']).cumprod()
df['Cumulative_Strategy'] = (1 + df['Strategy_Return']).cumprod()

# 6. 結果の可視化
plt.figure(figsize=(12, 6))
plt.plot(df['Cumulative_Market'], label='Buy & Hold (Market)')
plt.plot(df['Cumulative_Strategy'], label='Strategy (SMA Cross)')
plt.title('Backtest: SMA Crossover Strategy (USD/JPY)')
plt.legend()
plt.grid()
plt.show()

```

---

### 2. コードのポイント解説

* **`rolling(window=X).mean()`**:
指定した期間（X日）の平均値をずらしながら計算します。
* **`pct_change()`**:
「前日の終値から何％変化したか」を計算します。
* **`shift(1)`**:
**ここが最も重要です。** 今日のサイン（買うかどうか）が決まるのは「今日の終値」を見てからなので、実際に利益が出るのは「翌日の値動き」に対してです。1日分ずらすことで、未来を予測してしまう「先読みバイアス」を防いでいます。
* **`cumprod()`**:
累積積。複利で資産が増えていく様子をシミュレーションします。

### 3. このコードを改良するなら

このシンプルなコードをベースに、以下の要素を追加していくのが「自動売買開発」の醍醐味です。

1. **手数料の考慮**:
売買のたびにスプレッド（手数料）を引く処理を追加する。
2. **空売り（ショート）の追加**:
`Signal` を `-1` にすることで、下がった時に利益が出る設定にする。
3. **他の指標**:
RSI（買われすぎ・売られすぎ）やMACDなどを組み合わせて精度を上げる。

---

### 注意点：バックテストの罠

バックテストで成績が良くても、実際の取引で勝てるとは限りません。

* **過剰適合（オーバーフィッティング）**: 特定の期間だけに最適化しすぎてしまい、未来の相場では通用しない。
* **スリッページ**: API経由の注文では、チャートの価格と実際の約定価格がズレることがあります。

## [CSV保存について]

CSVとしてデータを保存することは、プログラムの実行時間を短縮し、データの信頼性を確保するために非常に重要なステップです。保存後の活用方法は、主に以下の4つのステージに分けられます。

---

### 1. データの「使い回し」による効率化

`yfinance` などのAPIを毎回叩いてデータをダウンロードすると、サーバーに負荷がかかるだけでなく、通信環境によっては時間がかかります。

* **活用例:** 一度CSVに保存しておけば、次回からは `pd.read_csv()` で一瞬でデータを読み込めます。インターネットがない環境でも開発・分析が続けられます。

### 2. バックテストの「高速化・詳細化」

CSVに保存されたデータは、Excelで手軽に眺めることも、Pythonで精密な計算をすることも可能です。

* **Excelでの目視確認:** 「本当にこのタイミングでサインが出ているか？」をセル上で手計算して確認できます。
* **独自の指標追加:** CSVに「5日移動平均」や「ボリンジャーバンド」などの計算結果を列として追加して上書き保存しておけば、重い計算を何度もやり直す必要がなくなります。

### 3. 他のツール・言語との連携

Python以外のソフトでチャート分析やシミュレーションを行いたい場合にCSVは「共通言語」になります。

* **TableauやPower BI:** データを可視化し、美しいダッシュボードを作成して相場を分析する。
* **機械学習ツール:** `Scikit-learn` などの機械学習ライブラリに読み込ませて、未来の価格予測モデルの「学習データ（教師データ）」として使用する。

---

### 4. 具体的な保存と読み込みのコード

```python
import yfinance as yf
import pandas as pd

# 1. データの取得
df = yf.download("USDJPY=X", period="1y")

# 2. CSVとして保存 (index=Trueで日付も保存)
df.to_csv("usdjpy_data.csv", index=True)

print("保存完了！")

# --- 後日、別のプログラムで使う時 ---

# 3. CSVから読み込み (日付をインデックスとして認識させる)
new_df = pd.read_csv("usdjpy_data.csv", index_col=0, parse_dates=True)
print(new_df.head())

```

---

### 5. 高度な活用：データベース化

データ量が増えてくると（例：1分足を10年分など）、CSVファイルが巨大になりすぎて読み込みが遅くなります。そうなった次は、以下のようなステップへ進みます。

* **SQLite / PostgreSQL:** データベースに保存し、必要な期間だけを高速に抽出（SQL）する。
* **Parquet形式:** CSVよりも圧縮率が高く、読み書きが圧倒的に速いデータ形式で保存する。

## [2000年以降の地政学的イベント]

2000年以降、金融市場（特にドル/円や株価指数）に大きな影響を与えた地政学的イベントを年表形式でまとめました。

バックテストの結果と照らし合わせると、「なぜこの年にボラティリティ（変動幅）が激しかったのか」を理解する助けになります。

### 2000年代：テロの脅威と戦争の時代

* **2000年:** **ITバブル崩壊**。地政学ではありませんが、米ドットコム企業の株価が暴落。
* **2001年:** **米国同時多発テロ（9.11）**。世界経済が震撼し、有事のドル買い・円買いが錯綜。
* **2002年:** ユーロ紙幣・硬貨の流通開始。欧州の統合が加速。
* **2003年:** **イラク戦争開戦**。原油価格の上昇要因に。
* **2004年:** 欧州連合（EU）に東欧など10カ国が加盟。
* **2005年:** ロンドン同時爆破テロ。
* **2006年:** 北朝鮮が初の核実験を実施。地政学的リスクとして定例化。
* **2007年:** サブプライムローン問題が表面化。
* **2008年:** **リーマン・ショック**（世界金融危機）。ロシア・ジョージア紛争。
* **2009年:** ギリシャの財政赤字粉飾が発覚（欧州債務危機の火種）。

---

### 2010年代：アラブの春とポピュリズムの台頭

* **2011年:** 東日本大震災（円が過去最高値を更新）。ビン・ラディン殺害。

* **2013年:** 中国による「一帯一路」構想の提唱。

* **2015年:** チャイナ・ショック（中国株暴落）。パリ同時多発テロ。
* **2016年:** **イギリスのEU離脱決定（Brexit）**、**トランプ大統領当選**。
* **2017年:** 北朝鮮による相次ぐミサイル発射と核実験。
* **2018年:** **米中貿易摩擦**が本格化（関税合戦）。
* **2019年:** 香港民主化デモの激化。

---

### 2020年代：パンデミックと大国間の衝突

* **2020年:** **新型コロナウイルス（COVID-19）の世界的大流行**。ロックダウン実施。
* **2021年:** 米軍のアフガニスタン撤退。バイデン政権発足。

## [変動率の計算]

「変動率」を計算することは、自動売買において**「どれだけのリスク（値動きの激しさ）に耐える必要があるか」**を知るために不可欠です。

一般的に投資で使われる「ボラティリティ（標準偏差）」と、直感的に分かりやすい「最大下落率・上昇率」の2パターンで、先ほどの2つの時期を比較計算してみましょう。

### Pythonによる変動率比較コード

```python
import yfinance as yf
import numpy as np

# データの取得
ticker = "USDJPY=X"
data = yf.download(ticker, start="2007-01-01", end="2024-12-31")['Close']

def calc_stats(series, name):
    # 1. 日次リターンを計算し、確実に数値配列として扱う
    returns = series.pct_change().dropna()
    
    # 2. 年率ボラティリティの計算（.std() の後に .item() で数値化）
    volatility = (returns.std() * np.sqrt(252) * 100).item()
    
    # 3. 期間内の最大値と最小値（.item() で数値化）
    max_price = series.max().item()
    min_price = series.min().item()
    price_range = max_price - min_price
    
    print(f"--- {name} ---")
    # これですべての変数が float（純粋な数値）になります
    print(f"年率ボラティリティ: {volatility:.2f}%")
    print(f"期間内最高値: {max_price:.2f}円")
    print(f"期間内最安値: {min_price:.2f}円")
    print(f"最大値幅: {price_range:.2f}円")
    print("-" * 20)

# 実行
calc_stats(data.loc["2008-01-01":"2009-12-31"], "リーマン・ショック期")
calc_stats(data.loc["2022-01-01":"2023-12-31"], "ウクライナ侵攻・円安期")

```

---

### 計算結果の解釈（シミュレーション値）

計算結果から、以下のような傾向が見えてくるはずです。

#### 1. 年率ボラティリティ（リスクの大きさ）

* **リーマン期:** 通常、為替のボラティリティは10%程度ですが、この時期は**15〜20%近く**まで跳ね上がることがあります。
* **2022年〜期:** 円安が急激に進んだため、リーマン期に匹敵、あるいはそれ以上の激しい変動率を記録しています。

#### 2. 最大値幅（強制ロスカットの指標）

* **2022年〜期:** 115円台から150円超えまで、約**35円**もの値幅があります。
* もし「1ドル＝115円」の時に、35円分の逆行（円高方向への変動）に耐えられない証拠金で自動売買を回していたら、口座が破綻していたことを意味します。

---

### 自動売買プログラムへの活用法

算出した変動率を元に、プログラムに以下のロジックを組み込むのが一般的です。

* **ATR (Average True Range) の活用:**
直近の変動率を計算し、値動きが激しい時は「損切り幅を広くする」または「取引量を減らす」といった調整を自動で行わせます。
* **リスク・リワード設計:**
ボラティリティが「12%」の通貨ペアで、利益確定を「0.1%」に設定すると、ノイズ（一時的な逆行）ですぐに損切りされてしまうため、変動率に合わせた目標設定を行います。
