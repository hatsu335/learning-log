### [GitHubリポジトリ内検索] 
**Copilotによる検索結果**
```
GitHub の通常の検索バー（Web UI）でリポジトリ内 Markdown ファイルから特定の文字列（今回の例は `#MySQL`）を検索する方法を、Web 操作・クエリ例・ローカルコマンドの３つで分かりやすくまとめます。

1) GitHub（Web UI）での手順（リポジトリ内を検索）
- リポジトリページに行く（例: https://github.com/hatsu335/learning-log）。
- ページ上部の検索ボックス（「This repository」になっていることを確認）に検索語を入力して Enter。
- 検索結果ページで「Code」タブを選択するとコード／Markdown 内の一致が出ます。
- 必要なら右側のフィルタ（Languages, Path, Filename など）で絞り込めます。

よく使うクエリ（検索ボックスにそのまま貼る）
- repo:hatsu335/learning-log "#MySQL" type:code
- repo:hatsu335/learning-log extension:md "#MySQL" type:code
- repo:hatsu335/learning-log path:mysql "#MySQL" type:code
- repo:hatsu335/learning-log filename:2025-12-29.md "#MySQL" type:code
- repo:hatsu335/learning-log language:Markdown "#MySQL" type:code

注意点：
- 検索バーに `#` を直接入れてもうまく動かない／URLにするときは `#` をエンコードして `%23` にする（例: https://github.com/hatsu335/learning-log/search?q=%23MySQL&type=code）。
- GitHub Code Search は通常ケースインセンシティブ（大文字小文字を区別しない）ですが、厳密な大文字小文字を指定する場合は `case:yes`（例: repo:... "#MySQL" case:yes type:code）を試してください。

2) リポジトリ内検索ボックスを使うときのフィルターの意味（参考）
- repo:owner/name — 指定リポジトリのみを検索
- path:dir — 指定ディレクトリ以下を検索
- extension:md / filename:xxx — ファイル拡張子／ファイル名で絞り込み
- type:code — コード検索（ファイル内容を検索）
- language:Markdown — 言語で絞る（Markdownなら.md系）

3) ローカル（クローン済みリポジトリ）で確実に検索するコマンド例
- ripgrep（推奨、速い）
  - 固定文字列検索（大文字小文字を区別）:
    rg -n -F '#MySQL' --glob '**/*.md'
  - 大文字小文字を無視:
    rg -n -i -F '#MySQL' --glob '**/*.md'
  - 正規表現（例："#MySQL" または "MySQL" を拾う）:
    rg -n '(^|\s)#?MySQL' --glob '**/*.md'

- git grep（Git 管理下で高速）
  - git grep -n -- '*.md' -e '#MySQL'

- 普通の grep（Linux/macOS）
  - grep -Rbn --include='*.md' '#MySQL' .

4) 正規表現や厳密一致を使いたいとき
- GitHub の Web 検索は記号や空白の扱いがやや特殊なので、複雑な正規表現はローカル（ripgrep/git grep）で行うのが確実です。
- ripgrep はデフォルトで正規表現を使い、`-F` で固定文字列（メタ文字無効）になります。

5) 実例リンク（今回の検索）
- すぐ開くなら（先ほど検索で使ったURL）:
  https://github.com/hatsu335/learning-log/search?q=%23MySQL&type=code

まとめ
- 単純に `#MySQL` を探すだけなら、リポジトリページの検索ボックスに `#MySQL`（必要なら先頭に repo:... を付ける）を入れて「Code」タブで見るのが手早いです。
- もっと正確に／正規表現で探したいならローカルで ripgrep ／ git grep を使うのが確実。

必要なら、あなたの好みに合わせて（例：正規表現で「#MySQL」だけを厳密に、または `MySQL` をタグ以外も含めて検索する等）具体的な検索クエリ／コマンドを作ります。どの検索方法を詳しく知りたいですか？
```

### [テーブル分割]
**内部結合**
```MySQL
SELECT
  post.id,
  message,  --双方のTABLEに1つしかないCOLUMN名はTABLE名の指定不要
  comments
FROM
  posts
INNER JOIN  --INNERは省略可能
  comments
ON
  posts.id = comments.post_id;
```
