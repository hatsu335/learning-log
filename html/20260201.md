## 2. Record & Comment 

### [navタグ]  
sectionと同じでブラウザで表現されることはない  
「このサイトを回避するためにはここを参照して」という情報開示  
検索エンジンのための情報で目次などに設定するとよい  

```html
<nav>
    <h2>目次</h2>
    <ol>
        <li><a href='#features'>サービスの特徴</a></li> 
        <li><a href='#plans'>提供中のプラン</a></li>
        <li><a href='#history'>サービスの沿革</a></li>
    </ol>
</nav>
```

---

### [ページ内リンク]  
ページ内へのリンク  
`aタグ`の`href属性`に`#`をつけて`id`を指定する  
リンク先には`id属性`を指定する  

```html
<a href="#history">

<section id="history">
```

---

### [header,footer]  
トップページのロゴや大見出しなどの導入的コンテンツに`header`を使用して区別する  

```html
<header>
    <img src="logo.png" alt="ロゴ画像" width="160" height="160">
    <h1>アニマルハウス</h1>
</header>
```
著作権などの最後に表示させるようなものに`footer`で区別する  
また、注釈的に小さく表示したい情報であれば`smallタグ`が用意されている  

```html
<footer>
    <small>(c) animalhouse.com</small>
</footer>
```

---

### [metaタグ]  
`meta`とは情報のための情報という位置づけ  
`<!DOCTYPE html>`は文書宣言へ`html`で書かれていますよという宣言  
`<html lang="ja">`はhtml文章は日本語であるという宣言  
`<head></head>`はhead タグはこの文書を解析して活用するプログラムに読んでほしい情報  
`<body></body>`はブラウザに表示して人に読んでもらいたい情報  
`<meta charset="UTF-8">`文字コードの指定(現在は`UTF-8`を必ず指定することに決まっている)  
`<title></title>`はブラウザのタグに表示される文字列を指定(ブックマークも)  
`<meta name="description" content=".......">`必ず`name属性`と`content属性`をセットにして、`name属性`の方は`description`、`content属性`にはこの文書の概要を指定すること  
`ファビコン`とはブラウザのタブやブックマークの横に表示されるアイコンのこと  
ファビコンの設定は`linkタグ`を使い`rel属性`を icon として、`href属性`を使って画像のファイル名を指定する  

```html
<!DOCTYPE html>              <!-- 最初に"HTML:5"と入力すると雛形が表示される -->
<html lang="ja">             <!-- 言語: 日本語 -->
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="Description" content="変わった人たちによる家事手伝いサービス">
    <title>アニマルハウス</title>  <!-- タグに表示される -->
    <link rel="icon" href="favicon.png">
</head>
```

`<aside></aside>`は本文とは関連性の薄いもの(広告など)を表している

### [articleタグ]  
`section`などのタグで囲むような箇所のうち、それが記事だったり投稿だったりといったコンテンツには`<article></article>`を使用する  
このタグも文章の区切りを明確にするだけなので、見た目は変わらない  
このコンテンツは他のサイトでも使ってほしいな、と思えるものは article タグの利用を検討してみると良い  

---

### [timeタグ]  

```html
<article>
    <h3>新製品</h3>
    <p>無茶苦茶すごくてビックリしました！言葉に表すことが難しいです！</p>
    <footer>
        <p>投稿日: <time>2026-2-1 11:00</time> 投稿者: hatsu335</p> <!-- datetime属性不要 -->
        <p>投稿日: <time datetime="2026-2-1 11:00">2月1日</time> 投稿者: hatsu335</p><!-- datetime属性必要 -->
    </footer>
</article>
```
日本語かつもっと短く、例えば 11 月 17 日とだけ書きたい場合、コンピューターにとって値が分かりにくいので`datetime属性`を使って値を与える必要がある  
`header`や`footer`タグは必ずしもページの最初と最後にしか付けられないという訳ではなくて `article`や`section`のような文章に区切りを付けるタグごとに付けても OK という点にも注意

### [文字参照とcodeタグ]
本文中に以下のように表示させたい場合、`＜`と`＞`は挙動がおかしくなってしまう  
```Bash
<article>とは  ->  とは   #このように表示されてしまう
```
以下のように調整する必要がある
```Bash
<article>とは  ->  &lt;article&gt;とは   #このように書き替えると「<article>とは」と表示される
```
プログラムのコードを表現する`<code></code>`を使って意味を明確にするのもアリ  
```Bash
<article>とは  ->  <code>&lt;article&gt;</code>とは   #codeタグを使うことで文章中でも分かりやすくなる
```
`＜`は`&lt;`とする  
`＞`は`&gt;`とする

## [フォーム]

### [form, テキストボックス, divによるスタイリング]  
`<form></form>`フォーム範囲の指定  
`<input type="text">`テキストボックス(1行) `typu属性`で`text`を指定  
`<textarea></textarea>`テキストボックス(複数行)  
`<div></div>`

```html
<form>
    <div>
        <input type="text">  <!-- 終了タグは不要 -->
    </div>
    <div>
        <textarea></textarea>
    </div>
</form>
```

上記コートで`divタグ`が無いとテキストボックスが横並びになる  
`divタグ`を指定すると横幅いっぱいの四角い領域を作るため、この場合は縦ならびになる  

---

### [label, id と for による関連付け]  
(非推奨)`<label></label>`でテキストを表示させ、`for属性`で`id属性`と関連付ける  
ブラウザ上では名前部分をクリックしてもテキストボックスが反応するようになる  

```html
<div>
    <label for="name">お名前</label>  <!-- for属性でidと関連付けする -->
    <input type="text" id="name">
</div>
<div>
    <label for="content">内容</label>  <!-- for属性でidと関連付けする -->
    <textarea id="content"></textarea>
</div>
```

(推奨)`labelタグ`内にテキストボックスを入れれば関連付けられるので、  
`for属性`で`id属性`は不要となる  

```html
<div>
    <label>
    お名前
    <input type="text" placeholder="例:山田太郎">  <!-- labelタグ内に入れる -->
    </label>
</div>
<div>
    <label>
    内容
    <textarea placeholder="例:商品が届きません"></textarea>  <!-- labelタグ内に入れる -->
    </label>
</div>
```

上記に追記した`placeholder属性`は、テキストボックス内に薄く参考テキストを入れることができる  
しかし、推奨されていない。参考テキストはテキストボックスの外に明記するのが一般的

### [チェックボックス]  
`<input type="checkbox">`チェックボックス  
`<fieldset></fieldset>`でグループ化  
`<legend></legend>`でグループの説明を入れられる  

```html
<div>
    <fieldset>  <!-- fieldsetによって入力部品をグループ化 -->
    <legend>対象の商品</legend>
    <label><input type="checkbox"> 商品A</label>  <!-- label内にあるので商品名と関連付いている -->
    <label><input type="checkbox"> 商品B</label>
    <label><input type="checkbox"> 商品C</label>
    </fieldset>
</div>
```

---

### [ラジオボタン]  
`<input type="radio" name="warranty">`ラジオボタン  
`name属性`を設定することで1つしか設定できないようにする  
下記の例では`wrranty`(任意)を3つに設定することで、3つのうち1つしか選択できないようになる  

```html
<div>
    <fieldset>
    <legend>延長保証</legend>
    <label><input type="radio" name="warranty"> 加入済</label>
    <label><input type="radio" name="warranty"> 未加入</label>
    <label><input type="radio" name="warranty"> わからない</label>
    </fieldset>
</div>
```

---

### [ドロップダウンリスト]  
`<select></select>`の中に`<option></option>`を入れる(ドロップダウンリスト)  
デフォルトでは1つしか選べない  

```html
<div>
    <label>
    種別
    <select>
        <option>-- お問い合わせ種別を選択してください --</option>
        <option>商品が届かない</option>
        <option>商品が壊れた</option>
        <option>間違えて注文した</option>
        <option>決済手段を変えたい</option>
        <option>その他</option>
    </select>
    </label>
</div>
```

---

### [リストボックス]  
ドロップダウンとほぼ同じで、`size属性`を指定するとリストボックスになる  
デフォルトでは同様に1つしか選べないが、`multiple`を宣言することで複数選べる  
ただし、複数選ぶ場合はチェックボタンを選択することが一般的  

```html
<div>
    <label>
    種別
    <select size="3" multiple>  <!-- multipleを宣言すると複数選択可能 -->
        <option>商品が届かない</option>
        <option>商品が壊れた</option>
        <option>間違えて注文した</option>
        <option>決済手段を変えたい</option>
        <option>その他</option>
    </select>
    </label>
</div>
```

---

### [ボタン]  
以下のように二通の方法がある  
`inputタグ`の方はボタンのテキストを表現するのに、`value属性`を使ってテキストで指定することしかできないが、  
`buttonタグ`の方は、この中に自由に記述することができるため、画像などを含めることもできる  
以上のことから`buttonタグ`を使う方がよいかも  

```html
<div>
    <button>送信</button>
    <input type="submit" value="送信">  <!-- どちらも全く同じ結果になる -->
</div>
```

---

### [入力値にあらかじめ値をセットしておく方法]
テキストボックスは`value属性`に値を設定  
チェックボックスは`checked属性`を設定  
リストボックスは`selected属性`を設定  
`textareaタグ`に関しては直接タグ内に値を記入する、空白や改行がそのまま反映するので確認必要  

```html
テキストボックス
<input type="text" value="山田太郎">

チェックボックス
<input type="checkbox" checked="checked">  <!-- 正式にはこのように書くが下記コードでよい -->
<input type="checkbox" checked>            <!-- 属性と値が同じであれば値を省略できる -->

ラジオボタン
<label><input type="radio" name="warranty" checked>  <!-- チェックボックス同様 -->

リストボックス
<option selected="selected">間違えて注文した</option>  <!-- 正式にはこのように書くが下記コードでよい -->
<option selected>間違えて注文した</option>             <!-- 属性と値が同じであれば値を省略できる -->

テキストボックス(複数行) textarea
<textarea>こんにちは。     <!-- 直接タグ内に書き込む -->
こんにちは。</textarea>    <!-- 空白や改行もそのまま反映するので確認しながら作りこむ -->
```

---

### [disabled属性 ボタン無効化]
`disabled属性`を設定することでボタンを薄くして無効化できる  
ただし条件を満たしたらボタンが押せるなどの挙動にするには`JavaScript`などが必要  

```html
<button disabled="disabled">送信</button>  <!-- 正式にはこのように書くが下記コードでよい -->
<button disabled>送信</button>             <!-- 属性と値が同じであれば値を省略できる -->
```

---

### [特定の値に特化した入力部品]  
属性に設定する値によって特定の値に特化できる  

```html
テキスト
<label>お名前 <input type="text"></label>

パスワード
<label>パスワード <input type="password"></label>  <!-- 入力値が●●●●となり隠れる -->

数値
<label>数量 <input type="number"></label>  <!-- 矢印が出てきてマウス操作で入力できる -->

日付
<label>日付 <input type="date"></label>  <!-- カレンダーが出てきて選択して入力できる -->
```
他にも`url`や`色`や`電話番号`に特化した部品もある  
ただ、テキストボックスとパスワード以外は便利ではあるが、  
ブラウザによって見え方や操作方法が異なったりするのと、  
古いブラウザではうまく動かなかったりするので、実装にあたっては注意が必要
