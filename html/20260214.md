## [meta情報について]

よく使われる **meta タグの一覧**をまとめ  
Web制作で「最低限必要なもの」と「用途別に追加するもの」を整理しておくと便利

### **1. 基本的にほぼ必須の meta タグ**
| 用途 | 例 | 説明 |
|------|------|------|
| 文字コード | `<meta charset="UTF-8">` | ページの文字コードを指定（UTF-8 が標準） |
| スマホ対応 | `<meta name="viewport" content="width=device-width, initial-scale=1">` | レスポンシブ表示の基本設定 |
| ページ説明 | `<meta name="description" content="ページの説明文">` | 検索結果に表示される説明文（SEO） |

---

### **2. SEO（検索エンジン）関連**
| 用途 | 例 | 説明 |
|------|------|------|
| 検索ロボット制御 | `<meta name="robots" content="index, follow">` | インデックス可否を指定 |
| キーワード（現在はほぼ不要） | `<meta name="keywords" content="HTML, CSS">` | ほぼ使われないが古い仕様として存在 |

---

### **3. スマホ・ブラウザ表示関連**
| 用途 | 例 | 説明 |
|------|------|------|
| テーマカラー | `<meta name="theme-color" content="#ffffff">` | スマホブラウザの上部色を変更 |
| アプリ名 | `<meta name="application-name" content="MyApp">` | Webアプリ名（PWA で使用） |

---

### **4. SNS（OGP / Twitter）関連**
※ OGP は `property="og:..."` を使うので name ではないですが、SNS 用としてまとめます。

| 用途 | 例 | 説明 |
|------|------|------|
| Twitter カード | `<meta name="twitter:card" content="summary_large_image">` | Twitter での表示形式 |
| Twitter サイト名 | `<meta name="twitter:site" content="@username">` | 投稿者のアカウント |

---

### **5. セキュリティ・プライバシー関連**
| 用途 | 例 | 説明 |
|------|------|------|
| referrer 制御 | `<meta name="referrer" content="no-referrer">` | リンク遷移時の参照元情報を制御 |
| color-scheme | `<meta name="color-scheme" content="light dark">` | ダークモード対応 |

---

### **6. http-equiv 系（name ではないが重要）**
| 用途 | 例 | 説明 |
|------|------|------|
| 自動更新 | `<meta http-equiv="refresh" content="30">` | 30秒ごとにページ更新 |
| 互換表示 | `<meta http-equiv="X-UA-Compatible" content="IE=edge">` | 古い IE の互換モード回避 |

---

### **最低限これだけ入れておけばOK（実用セット）**

これが現代の Web ページの基本セット

```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<meta name="description" content="ページの説明文">
```

## [背景画像のカスタマイズ]

### 1.ブレンドモード

```css
background-color: #0bd;    <-- ブレンドする色を指定
background-blend-mode: hard-light;  <-- ブレンドモードを指定
```

#### ブレンドモードの主な値

| 値 | ブレンドモード |
|------|------|
| multiply | 乗算 |
| screen | スクリーン |
| overlay | オーバーレイ |
| darken | 暗く |
| lighten | 明るく |
| color-dodge | 覆い焼きカラー |
| color-burn | 焼き込みカラー |
| hard-light| ハードライト |
| soft-light | ソフトライト |
| difference | 差の絶対値 |
| exclusion | 除外 |
| hue | 色相 |
| saturation | 彩度 |
| color | カラー |
| luminosity | 輝度 |

### 2.グラデーションカラー

```css
background-image: linear-gradient(#c9ffbf, #ffafbd);  <-- #c9ffbfから#ffafbdへのグラデーション
```

#### グラデーションカラーの主な値

| 値 | グラデーションの形状 |
|---|---|
| linear-gradient | 線形グラデーション |
| radial-gradient | 円形グラデーション |

### 3.ブレンドモードとグラデーションカラーのコンビネーション

#### `background-image`プロパティで背景画像とグラデーションカラーを`,`で区切って両方指定する

```css
background-image: url(../images/main-bg.jpg),linear-gradient(#c9ffbf, #ffafbd);
background-blend-mode: luminosity;
```

## [TOPページとCSSの全体像]

HTML
```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="ウェブページ作成の練習">
    <title>Web CAFE</title>
    <link rel="stylesheet" href="https://unpkg.com/ress/dist/ress.min.css">
    <link href="https://fonts.googleapis.com/css?family=Philosopher" rel="stylesheet">
    <link rel="stylesheet" href="css/style.css">
    <link rel="icon" href="images/favicon.png" type="image/png"> <!--ファビコン設定-->
</head>
<body>
    <div id="home" class="big-bg">
        <header class="page-header wrapper"> <!-- class 2種類設定 -->
            <h1><a href="index.html"><img class="logo" src="images/logo.svg" alt="Webカフェホーム"></a></h1>
            <nav>
                <ul class="main-nav">
                    <li><a href="news.html">News</a></li>
                    <li><a href="menu.html">Menu</a></li>
                    <li><a href="contact.html">Contact</a></li>
                </ul>
            </nav>
        </header>

        <div class="home-content wrapper">
            <h2 class="page-title">We'll Make Your Day</h2>
            <p>おしゃれなカフェで癒されてみませんか？無添加の食材で体の中からリフレッシュ。</p>
            <a class="button" href="menu.html">メニューを見る</a>
        </div>
    </div>
</body>
</html>
```

CSS
```css
@charset "utf-8";

/* 挙動確認用 backcolor */
body {
    /* background-color: beige; */
}

    /* background-color: pink; */

.home-content {
    /* background-color: skyblue; */
}

    font-size: 100%; /* ユーザーの指定した文字サイズを正しく反映させるため */

body {
    font-family: "Yu Gothic Medium", "游ゴシック Medium", YuGothic, "游ゴシック体", "ヒラギノ角ゴ Pro W3", sans-serif;
    line-height: 1.7; /* 行の高さ指定 */
    color: #432;
}

    text-decoration: none; /* <a>タグの傍線の指定 */
}
.logo {
    width: 210px;
    margin-top: 14px;
}
.main-nav {
    display: flex; /* 横並びを指定 */
    font-size: 1.25rem;
    text-transform: uppercase; /* 大文字に変換 */
    margin-top: 34px;
    list-style: none;
}
.main-nav li {
    margin-left: 36px;
}
.main-nav a {
    color: #432;
}
.main-nav a:hover {
    color: #0bd; /* マウスホバーで色変更 */
}
.page-header {
    display: flex; /* 横並びを指定 */
    justify-content: space-between; /* 両端へ配置 */
}
.wrapper {
    max-width: 1100px; /* 横幅最大設定でバランス調整 */
    margin: 0 auto; /* 中央配置 */
    padding: 0 4%; /* スマートフォン向け余白指定 */
}

/* HOME */
.home-content {
    text-align: center; /* 画面中央と余白の指定 */
    margin-top: 10%;
}
.home-content p {
    font-size: 1.125rem; /* pタグへのフォントサイズと余白の指定 */
    margin: 10px 0 42px;

/* 見出し */
.page-title {
    font-size: 5rem;     /* フォントの指定 */
    font-family: 'Philosopher', serif;
    text-transform: uppercase;
    font-weight: normal;
}

/* ボタン */
.button {
    font-size: 1.375rem;  /* フォント、色、角丸、余白の指定 */
    background-color: #0bd;
    color: #fff;
    border-radius: 5px;
    padding: 18px 32px;
}
.button:hover {
    background-color: #0090aa; /* カーソルをボタンに重ねた時の色を指定 */
}

/* 大きな背景画像 */
.big-bg {
    background-size: cover; /* 画像縦横比率をのままで画面いっぱいに広げたいとき */
    background-position: center top;
    /* background-color: blueviolet; 背景色を設定（ブレンドモード用） */
    /* background-blend-mode: darken; ブレンドモードを指定 */
}
#home {
    background-image: url(../images/main-bg.jpg); /* 画像と画面の高さの指定 */
    min-height: 100vh;
}
#home .page-title {
    text-transform: none; /* テキストの大文字、小文字、全角の指定。noneは変換しない指定 */
}
```
