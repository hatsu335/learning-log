## [復習でカードを作成]

index.html
```HTML
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <section>
        <h1>ワンタッチ</h1>
        <p>自動製缶機でサイド貼りと底貼りを行い。箱を整形する時はワンタッチで組み立てることができる。</p>        
    </section>
</body>
</html>
```
style.css
```css
@charset "utf-8";

body {
    margin: 0;
    font-family: "Helvetica Neue", Arial, "Hiragino Kaku Gothic ProN", Meiryo, sans-serif;
}

section {
    border: 1px solid lightgray;
    width: 400px;
    border-radius: 8px;
    margin: 32px auto;
    overflow: hidden;
}

h1 {
    background-color: #ebf6f7;
    margin: 0;
    text-align: center;
    font-size: 20px;
    border-bottom: 1px solid lightgray;
    padding: 8px;
}

p {
    background-color: #fef4f4;
    margin: 0;
    line-height: 1.6;
    padding: 8px;
}
```
CSSまで到達すると`section`のありがたみが分かる
