## [ボックスモデル]

### 要素の領域

`HTMLの要素`を配置すると四角いボックスの領域が確保されていく、その領域を`content box`という  
プロパティを使って、こちらのボックスにスタイルをつけていくことができる  
`border`というプロパティを使えば、この周囲に境界線をつけることができて、この境界線までを含めたボックスは`border box`と呼ぶ  
さらに`padding`というプロパティを使えば、`border`の内側に余白をつけることができて、ここの領域のことを`padding box`と呼ぶ  
さらに`margin`というプロパティを使って、`border`の外側に余白をつけていくこともできて、そうすれば他要素との間に間隔をあけることができるようになる  
`margin`まで含めた領域のことを`margin box`と呼ぶ  


ボックスモデル
```Bash
┌─────────────────────────────────┐
│            margin box           │
│ ┌─────────────────────────────┐ │
│ │  border box                 │ │
│ │ ┌─────────────────────────┐ │ │
│ │ │       padding box       │ │ │
│ │ │ ┌─────────────────────┐ │ │ │
│ │ │ │                     │ │ │ │
│ │ │ │     content box     │ │ │ │
│ │ │ │                     │ │ │ │
│ │ │ └─────────────────────┘ │ │ │
│ │ └─────────────────────────┘ │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```
これらのプロパティの他に`width`や`height`というプロパティもよく使われるが、デフォルトではこの`content box`の幅と高さを操作するために使う  
ただ`width`と`height`ですが、WEBデザインで要素の幅と高さというと、通常はこの`border`までを含めた領域をさすことが多いので、こちらの`border box`のサイズを指し示すように変更することもできる
